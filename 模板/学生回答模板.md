## 纪律

| 规则 | 说明 |
|---|---|
| **只增不改** | 学生写过的答案永远不覆盖；评估结论追加在下方 |
| **空围栏即未答** | 围栏内为空 = 尚未作答，导师不发评估 |
| **末尾两区占位** | `最终复评结果` / `正确答案与解析` 由导师在复评通过后填写 |
| **优先于教学文档** | 本文件的最终复评结论，优先于教学引导里的历史勾选 |
