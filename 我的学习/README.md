# 我的学习（Your Learning Data）

> **AI 导师会把你的全部学习记录写在这个目录里。** 你不需要手动改任何文件。

---

## 目录长什么样

```
我的学习/
├── 00-学习档案.md              ← 【总状态】学到哪、掌握什么、有什么挂起
└── 学科/
    ├── Python/
    │   ├── 00-摸底测试.md
    │   ├── 00-课程路线.md
    │   ├── 01-变量与数据类型/
    │   │   ├── 01_教学引导.md    ← AI 写的讲解 + 题目
    │   │   └── 01_学生回答.md    ← 你在这里作答
    │   └── 02-条件与循环/
    └── 英语/
        └── ...
```

---

## 三条纪律

| 纪律 | 说明 |
|---|---|
| **只增不改** | AI 不会覆盖你写过的答案，评估结论追加在下方 |
| **随时可关** | 状态只写在 `00-学习档案.md` 的 🚦/📊/⏳ 三处，关掉再回来能接上 |
| **不进 git** | 本目录已被 `.gitignore` 忽略（除本文件与起始档案），不会被公开仓库分发 |

---

## 你要做什么

**什么都不用做。** 只做两件事：

1. **在 `01_学生回答.md` 里写答案**（AI 会告诉你路径）
2. **写完跟 AI 说「完成了」**

AI 会自动：重新读文件 → 三维评估 → 帮你改错并讲透 → 落档 → 发下一课。

---

## 想换学科？

直接跟 AI 说「我要学英语」。它会：
- 在 `学科/英语/` 下建一套新的
- 走一遍需求收集 + 摸底测试
- 原来的学科记录**原样保留**，不会丢

---

## 想删掉重来？

删掉 `学科/` 下对应目录即可。`00-学习档案.md` 里的 📊 掌握表也一并清理（或让 AI 帮你清理）。
