# 学生回答模板（Student Answer Template）

> 复制为 `NN-<课名>/01_学生回答.md`，**题目与教学引导镜像同题**。
> 本文件是**唯一学习证据** —— 是否掌握，以本文件的「最终复评结果」为准。
> ⚠️ **按轮次追加**：初始只放第一轮的 1–3 题；学生答完、本轮全 ✅ 后，再追加下一轮。
> 顶部模块进度与本次技能清单分别展示，与对话、教学文档一致；由导师独立核对两种证据，学生直接在本轮题下作答。

## 纪律

| 规则 | 说明 |
|---|---|
| **只增不改** | 学生写过的答案永远不覆盖；评估结论追加在下方 |
| **顶部展示可更新** | 模块条与技能清单独立推导，只替换显示区，原答、提示记录和历史评估保持不变；未知模块范围显示待确定，不编造分母 |
| **按轮次追加** | 初始只放第一轮题目；上一轮全 ✅ 后才追加下一轮 |
| **空作答位即未答** | 空白文字区或空代码围栏都不算作答；模板说明不算答案，导师不发评估 |
| **末尾两区占位** | `最终复评结果` / `正确答案与解析` 由导师在**整课通过后**填写 |
| **优先于教学文档** | 本文件的最终复评结论，优先于教学引导里的历史勾选 |

每轮评估接在该轮已有作答之后，用一个「第 N 轮评估」标题承载逐题结论、必要的纠错解析和技能判定；先用一句话指出具体成果，不再另建成长报告、成就墙或重复进度汇总。整课最终复评与解析仍按协议保留。
