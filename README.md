**打开这个文件夹，就有一位一对一导师。**

一个 Markdown 协议 —— 任何 AI 工具打开它，都会变成你的私人老师：
先摸底、再上课、批作业、把「你哪里错了、为什么错」讲透，然后记下进度，等你下次回来。

**想学透一本书或一份资料？直接发给它** —— 它按资料的真实章节拆成一课一课，一步一步教你，每课都逼你作答。

**使用者不需要安装任何东西。** 没有 Node、没有 npm、没有 API Key、没有账号。

## 60 秒开始

**别急着往下读。** 你现在只要做这四件事：

| # | 做什么 | 你会看到 |
|---|---|---|
| **1** | 用 AI 工具**打开这个文件夹**（不是里面的某个文件） | 左侧文件树里出现 `AGENTS.md` |
| **2** | 说一句：`我是学生，请先读 AGENTS.md，然后开始。` | AI 说「我已经读完协议」并复述规则条数 |
| **3** | 问它：`AGENTS.md 的「硬规则」有几条？` | 答出 **12 条** = 规则真的生效了 |

## 为什么需要这个

AI 已经足够会教。**缺的从来不是内容，是那个盯着你的人。**

| 你现在的处境 | StepsToGreat 怎么解决 |
|---|---|
| 问 AI「我该怎么学 Python」，它给你一份路线图，然后就没有然后了 | AI 出摸底测试 → 定你的真实起点 → 排路线 → **发第一课** |
| 学完一课，没人检查你到底会不会 | 三维评估，**全 ✅ 才允许推进下一课** |
| 做错了，AI 说「不完全正确哦」——你还是不知道自己错在哪 | 小问题**直接帮你改**，并讲透「你写的 → 错在哪为什么 → 我改成什么」 |
| 关了对话就失忆，下次得从头解释 | 状态落盘在文件里，**换个工具、隔一个月回来都能接上** |
| 换了 AI 工具，之前的记录全废 | 数据是普通 Markdown，**换任何工具都不丢** |
| 手里有一本书 / 一份资料，翻了三页就放下 | **发给 AI，它把资料拆成课，一节一节带你过** |

### 和「直接问 AI」的区别

| | 直接问 AI | StepsToGreat |
|---|---|---|
| 有人格设定 | 每次要重新解释「你是我的老师」 | ✅ 写死在 `AGENTS.md`，零成本 |
| 记得你学到哪 | ❌ 靠上下文，关了就忘 | ✅ 落盘在 `我的学习/00-学习档案.md` |
| 会逼你练 | ❌ 你问它才答 | ✅ 出题 → 等你说「完成了」→ 评估 |
| 会挑你错 | ⚠️ 通常只给正确答案 | ✅ 三段式讲透，区分「手滑」和「真不会」 |
| **会追问你的需求** | ❌ 你说「教我英语」它就开始教 | ✅ **一路追问到它确认真的理解你** |
| 换工具 | ❌ 记录全丢 | ✅ 换工具照用 |
| 数据归属 | 平台 | ✅ 你自己的文件夹 |

### 这套规矩是怎么来的：不是拍脑袋，是实测出来的

**这一节是本项目与「又一个提示词合集」最大的性格差异。** 每一条规则都应该能说出它是被哪次实测逼出来的。

| # | 验证方式 | 抓到了什么 | 报告 |
|---|---|---|---|
| **1** | **8 份学科仿真** —— AI 扮演导师跑完整教学对话（含真实错误、反复追问、挫败情绪），再从对话里提炼缺陷 | 8 个学科**全部需要修补**；**6 个的核心症状是同一个**（② ③ 归属判不出来）→ 因此加了「裁决口诀」 | [`docs/simulations/`](./docs/simulations/) |
| **2** | **弱模型当探针** —— 刻意用最低推理档跑，因为强模型会**猜**出协议没写清的地方、反而掩盖缺陷 | 协议本身 **12/12**；另有 4 处真缺陷（2 个文档内部矛盾 + 2 个协议空白） | [`docs/weak-model/WEAK-MODEL-REPORT.md`](./docs/weak-model/WEAK-MODEL-REPORT.md) |
| **3** | **端到端跑测** —— 完整走一遍「首次使用 → 摸底 → 路线 → 第 1 课 → 三轮教学 → 整课闭环 → 落档」 | 1 个协议空白 + **1 个会让每个用户都踩到的模板坏链接缺陷** + 2 个校验器误报 | [`docs/E2E-RUN-REPORT.md`](./docs/E2E-RUN-REPORT.md) |
| **4** | **状态校验器** —— 12 条不变式，检查你的档案是不是自洽 | 能查出「标了已掌握却没有复评证据」「上一课没过就往下走」「同一份文档两份复评区」 | [`协议/04_状态机.md`](./协议/04_状态机.md) + [`tests/`](./tests/)（19 组回归用例） |

**三个数字，说明「加规则 ≠ 提价值」**：

| 数字 | 含义 |
|---|---|
| **8 个学科全部需要修补** | 三维评估的**机制**是完整的，但**判据**是按维度描述的，不是按错误描述的 |
| **133 条改动建议 → 只采纳 5 条** | 报告的价值是**证据**，规则只取其中会「判据打架」的部分。**明确拒绝了 7 条**，理由写在报告里 |
| **12 条不变式 + 19 组回归用例** | 「先有真实失误、才加规则」—— 每条不变式都能指出它是被哪次实测踩出来的 |

> **最重要的一条元结论**（出自 8 份仿真）：
> **三维评估的「机制」是完整的，但「判据」是按维度描述的，不是按错误描述的。**
> 导师真正需要的是反过来的：**拿到一个错，能查到它属于哪一维。**
> 修这一处，比修 133 条都值 —— 这就是 `协议/00_导师协议.md` §3 那条裁决口诀的由来。

### 为什么效果不一样：AI 会一直追问，直到真正理解你

普通 AI 的最大问题不是答得差，是**它从来不确认自己理解对了没有**。
你说「教我英语」，它就开始教 —— 教谁？考四六级还是口语？每天能学多久？基础如何？它全不知道，也**不问**。

本项目把「**追问到你确认为止**」写进了协议。AI 第一次接手时会像这样：

```
你：教我英语。

AI：在开始前，我要确认我真的理解你了 —— 答到我能复述你的需求为止。

    1. 你说「学英语」，具体是为了什么？
       a) 应试（四六级 / 雅思 / 考研）
       b) 能开口交流
       c) 能读文献 / 看剧
    2. 你现在什么水平？找一篇英语短文读 30 秒，告诉我大概懂几成。
    3. 每天能稳定投入多久？（说真实值，不说理想值 —— 我会按这个排课）

……（你回答后，AI 复述一遍它理解的需求）……

AI：我理解的目标是这样的 ——
    「4 个月内考过六级，当前阅读约五成，每天能学 40 分钟，周末可加倍。
     优先补阅读和听力，写作考前突击。」

    对吗？有偏差就纠正我，**确认之前我不会开始教**。
```

**关键设计**：追问不是聊天，是**消除歧义** —— 每个答案都会变成摸底测试和课程路线的输入。
你之后说的每一句「为什么这么排课」，答案都能追溯到第一天你确认过的需求。

> 这套追问机制同样由 `AGENTS.md` 约定 —— **换任何 AI 工具，它都会这么问**。

### 想不清楚的事，也可以让它一直质询你

有些时候你要的不是「学一门课」，而是**把一件事想清楚**：要不要换方案、这段需求到底在说什么、这个决定该怎么落。
这种时候缺的不是答案，是**有人一路问到你说不出话为止**。

同一套追问机制换到这种场景，会变成这样：

| 规矩 | 内容 |
|---|---|
| **只问「现在就能问的」** | 每个问题都建立在**已经定下来的答案**之上；依赖别的未决问题的，这一轮不问，排到后面的轮次 |
| **一轮问全 + 每题附推荐答案** | 当前这一层的所有问题**一次列全、编号**，每题给出**推荐答案** —— 你只需说「同意 / 换一个」 |
| **你的回答长出下一轮** | 定下来的决定把边界往外推，之前问不了的问题自己浮上来；一轮一轮，直到**没有未决项** |
| **事实它查，决定你拍** | 翻文件 / 查资料能解决的，不许拿来问你；摆到你面前的只有「你说了算」的事 |
| **不确认不动手** | 你把最终的理解复述一遍、双方对上，它才开始做 |

**一边问一边沉淀**：商量出来的结论可以当场落成两份文档 ——

① **决策记录**：一条 = 背景 / 有哪些选项 / 定了哪个 / 为什么 —— 见 [`docs/adr/`](./docs/adr/)；
② **术语表**：同一个词，整个项目里只准有一个意思 —— 见 [`CONTEXT.md`](./CONTEXT.md)。
目的很朴素：**三个月后，你自己也想得起当初为什么这么定。**

> 一句话区别：**摸底**是定学习起点（有题、不打分）；**质询**是定决策（无题、无对错，只有你说了算）。

## 想学透一本书 / 一份资料？发给 AI，它一步一步教你

**这是本项目最常用的用法**：你不需要先会什么，也不需要先列大纲 ——
**把书或资料丢进来，AI 负责拆课、讲课、出题、批改、记进度。**

```
你：资料我放在 资料/ 里了 —— 《XXX》全本 PDF，我要学透它。

AI：（先读文件 → 摸清目录与实际内容）
    在开始前，我要确认我真的理解你了：
    1. 你要「学透」到什么程度？ a) 应付考试  b) 能上手用  c) 能给别人讲
    2. 每天能稳定投入多久？
    3. 这本书哪几章是重点 / 哪几章可以先跳过？
    （你回答 → AI 复述一遍 → 你确认）

AI：第 1 课 · 第 1 章 <实际小节名>
    📁 文档位置：我的学习/学科/XXX/01-第1章/
    📖 本课重点：……（**出自《XXX》第 1 章第 2 节**）
    ✅ 你的任务：第 1 轮 2 题（1–3 题）
    → 你在 01_学生回答.md 里作答 → 说「完成了」

AI：（重新 read 你的答案 → 三维评估 → 小问题直接代改并讲透 /
     大问题引导你自己推）→ 全 ✅ 落档 → **追加第 2 轮 / 发第 2 课**
```

**你就是一路说「完成了」**，剩下的：
摸底 → 按书的**真实结构**拆成一课一课 → 每课两个文档 → 三维评估 → 落档 → 下一课。

### 它和「让 AI 总结这本书」的区别

| | 让 AI 总结一本书 | StepsToGreat |
|---|---|---|
| 产出 | 一份几千字的摘要，你读完就还回去了 | **一节课一节课**，每课都逼你作答 |
| 有没有检验 | ❌ 没有 | ✅ 三维评估，全 ✅ 才允许推进下一课 |
| 讲到第几章 | 一遍就到底 | **落盘在 `00-学习档案.md`**，随时关掉随时接上 |
| 出错怎么办 | 摘要糊过去 | 小问题代改 + 讲透，大问题让你自己推 |
| 引用 | 「书中提到…」（无法核对） | **「出自 `<文件名>` 的 `<具体小节>`」**（可核对） |
| 学到一半 | 只能重新问一遍 | 隔一个月回来，说「继续」 |

### 怎么发（三步）

| 步骤 | 做什么 |
|---|---|
| **1. 放进去** | 把文件复制到 [`资料/`](./资料/)（子目录随意分，如 `资料/考研数学/`）。**一次放一份，别把十本书一起丢** |
| **2. 说一句** | 「资料在 `资料/` 里了，我要学透《XXX》，目标是……每天能学 X 分钟」 |
| **3. 开始答** | AI 会先追问 + 摸底，然后发第一课。之后你只需要答完说「完成了」 |

| 格式 | 支持度 |
|---|---|
| `.md` `.txt` | ✅ 最好 |
| `.pdf`（文字版） | ✅ 好（**扫描件需 OCR**） |
| `.docx` `.pptx` | ⚠️ 一般，建议另存为 `.md` |
| 图片 | ⚠️ 看工具是否支持视觉 |
| 视频 | ❌ AI 读不了 —— **请给字幕或你的笔记** |

> 完整说明与纪律（**只增不改** / 不进 git / 标注来源）：[`资料/README.md`](./资料/README.md)

### 三条硬约束（防止 AI 糊弄你）

| 约束 | 含义 |
|---|---|
| **按实际内容教** | 导师必须读你放的文件，**不许凭记忆编章节号和书里的原话** |
| **引用到小节** | 每个知识点都要能说出「出自 `<文件名>` 第几节」—— 说不出就是没读 |
| **不编书单** | 本项目**不会**给你一串查不到的书名章节；没有资料时，它就把内容直接讲透 |

> 💡 **没有现成书怎么办？** 一样能用 —— 说清「我要学 X，我的基础是 Y」，
> 导师自己把内容讲清楚写进教学文档，规则完全相同（`资料/` 只是**更好**，不是**必须**）。

## 适合谁，不适合谁

**先说清楚，免得你白装一次。**

| ✅ 适合 | ❌ 不适合 |
|---|---|
| 自学一门技能，但总半途而废 | 想要现成的课程视频 / 教材 —— **本项目不提供内容** |
| 需要一个盯着你、检查你的角色 | 只想要「问一句答一句」的助手 |
| 目标明确（考试 / 项目 / 补短板） | 完全没目标，只想随便看看 |
| 愿意**动手写答案**（打字或纸笔） | 只想被动听讲，不愿做题 |
| 想长期学（几周到几年） | 只想临时查一个知识点 |
| 手里有自己的资料（教材 / 真题 / 笔记） | 期待 AI 凭记忆编课程 |

> **一句话**：如果你要的是「有人出题、批改、逼你练」，这个项目对口。
> 如果你要的是「内容」，请去找课程 —— 本项目负责的是**那个盯你的人**。

## 它是怎么工作的

```mermaid
flowchart TD
    A["① 首次打开<br/>AI 读 AGENTS.md"] --> B["② 需求收集<br/>问你 3 个问题"]
    B --> C["③ 摸底测试<br/>5–8 题"]
    C --> D["④ 定起点 + 排路线"]
    D --> E["⑤ 发第一课"]
    E --> F["⑥ 你作答"]
    F --> G["⑦ 你说「完成了」"]
    G --> H["⑧ AI 重新读文件<br/>不靠记忆"]
    H --> I["⑨ 三维评估<br/>全部题目一次列全"]
    I --> J{"全 ✅ ?"}
    J -->|"否"| K["小问题：直接代改 + 讲透<br/>大问题：引导你自己推导"]
    K --> G
    J -->|"是"| L["⑩ 落档 + 发下一课"]
    L --> F
```

**全程你只需要说两句话**：开始时的第一句，和每次的「**完成了**」。

### 每课产出两个文档

**这是教学模式的载体** —— 每一课都在文件夹里生成两个 Markdown：

```
我的学习/学科/Python/03-for循环/
├── 01_教学引导.md    ← 导师写：讲解 + 例题 + 题目（按轮次排布）
└── 01_学生回答.md    ← 你写：在题目下的空位作答；末尾留两个占位区给导师填
```

| 文档 | 谁写 | 里面有什么 |
|---|---|---|
| **`01_教学引导.md`** | 导师 | 为什么要学 → 核心概念 → 示例 → 新旧对比 → 常见陷阱 → 和之前知识的关联 → 本节重点 → 题目（按轮次） |
| **`01_学生回答.md`** | **你** | 本轮的题目 + 你的作答；**末尾两个占位区**：`## 最终复评结果`（逐题三维表）、`## 正确答案与解析`（三段式） |

**两个关键约定**：

| 约定 | 说明 |
|---|---|
| **回答文档 = 唯一学习证据** | 是否掌握，**只以它的「最终复评结果」为准** —— 不看你聊了什么，不看 AI 说了什么 |
| **按轮次追加，不是一次列全** | 回答文档初始**只有第一轮题目**（1–3 题）；本轮全 ✅ 后，导师再**追加**下一轮 —— 否则你一眼看到全部题目，等于一次全发 |

> 💡 **为什么是「两个文档」而不是「一个对话」**：
> 对话关掉就没了，文档能留下来。三个月后你想复习「当初 for 循环我错在哪」，

## 核心机制

### 一、三维评估，全 ✅ 才推进

每个知识点按三个**独立**维度评估 —— 这是本项目的灵魂：

| 维度 | 编程 | 英语 | 数学 | 文科 |
|---|---|---|---|---|
| ① **概念理解** | 懂不懂 | 读懂没有 | 概念清不清 | 理解到位吗 |
| ② **逻辑正确** | 算法/边界 | 表达达意吗 | 推导/计算 | 论证成立吗 |
| ③ **规范表达** | 语法可编译 | 语法规范 | 推导规范 | 表述规范 |

> **三项全 ✅ = 掌握，才允许推进下一课。** 任意一项 ⚠️ 就继续练。

**为什么必须三个独立？** 只有概念 → 能说不会做；只有逻辑 → 做对了说不清；只有规范 → 写得漂亮但理解错。
合并成一个「综合分」就分不清「懂了但手滑」和「根本没懂」—— 而这两种需要完全不同的处理。

#### 一个错误该进哪一维？—— 裁决口诀

三维评估最大的实操难点不是「三个维度是什么」，而是**拿到一个具体的错，判不出它属于哪一维**。
8 份学科仿真里 **6 个学科的核心症状都是这一条** —— 判不出来就意味着**判定不可复现**
（换一个导师评同一份卷子会得出不同结论），而「全 ✅ 才推进」整个机制就建立在判定的确定性上。

所以协议 §3 给了这条口诀，按顺序问：

| 顺序 | 问题 | 判定 |
|---|---|---|
| 1 | 学生**说的东西本身就不对**（概念错、术语错、事实错）？ | **① 概念理解** |
| 2 | 概念没错，但**推理链断了 / 不成立**？ | **② 逻辑正确** |
| 3 | 前面都对，只是**不合该学科的形式规范**？ | **③ 规范表达** |

**口诀：说错了 → ①；想错了 → ②；写错了 → ③。**
同时命中两维 → **按更靠前的判**（① > ② > ③）；**费曼题只评 ①**，另两项标 `— 不适用`。
各学科的边界案例表附在 `学科包/` 里（只列有争议的，不重抄全部判据）。

## 1️⃣ 问题 2：循环范围错了

**你的原答案**

    print(i)

**问题在哪里**

- 这是 Python「左闭右开」的约定，初学者最容易踩

    print(i)

> ① 「**问题 1 没问题，你答得对**」—— 协议规定没改的题也要明确说通过，否则学生会以为「没说 = 有问题」。
> ② 「**我们再进第二轮**」—— 一轮只有 1–3 题，本轮全 ✅ 才发下一轮。

### 三、状态只写在三个地方

| 位置 | 回答什么 |

这不是理论担忧 —— 弱模型实测**真的**在回答文档里写了两遍「最终复评结果」（一份已填、一份还是空占位），
而当时的校验器抓不到（它只找第一个小节，填了就过）。因此补了不变式 I11，专门查「同一信息写多处」。

### 四、费曼学习法：讲不清 = 没真懂

**最危险的不是「不会」，是「你以为你会」。**

普通的题可以靠套公式、背模板、凭熟悉度蒙对 —— **答对不等于真懂**。
所以导师会**偶尔**让你用**外行能听懂的话**把一个概念讲一遍：

```
AI：不许用这些词：<闭包>、<作用域>、<引用>

    用你妈能听懂的话解释：为什么这个函数「记住」了外面的变量？
    3–5 句话说清即可。

你：（讲……）

AI：你用「随身背包」这个类比很好 —— 背包里装的就是它记住的变量。
    但你说「背包会自己更新」这里卡住了，那正是关键。
    重讲这一段就行，不用全篇重来。
```

**为什么它比普通题更有价值**：

| 普通题 | 费曼题 |
|---|---|
| 可以套公式、背模板、靠熟悉度蒙对 | 必须自己组织语言，套不了 |
| 答对 ≠ 真懂 | **讲不清 = 一定没懂**（几乎不会误判） |
| 测「能不能做」 | 测「**是不是真理解**」 |

**频率是自适应的，不会频繁问你**：

| 更该问 | 可以少问 |
|---|---|
| 抽象概念、原理、易混概念 | 纯操作、记忆性内容 |
| 你刚接触这个领域 / 此前讲得不好 | 你已经能熟练应用 / 此前讲得好 |
| **大模块收尾**（如「OOP 学完了」） | 模块中途、推进顺利时 |

**硬性约束**（写进协议，防止滥用）：

- ✅ 大模块收尾**必做 1 次**；一个知识点**最多问 2 次**
- ❌ **不许每课都问**；不许连续两轮都出费曼题
- ✅ 学生说「我不想讲，直接考我」→ **尊重他**，改用普通题
- ✅ 费曼题**只评概念理解**，该轮**只出这一题**（它比普通题耗时）

> 各学科的用法不同，`学科包/` 里有专门一节：
> 编程**禁止写代码**、理科**禁止写公式**、文科**必须举具体例子**、应试场景**要克制使用**。

> 想验证**协议有没有被遵守**？跑 `node _tools/validate-state.mjs` ——
> 它按 [`协议/04_状态机.md`](./协议/04_状态机.md) 的 12 条不变式检查你的学习档案，
> 能查出「标了已掌握却没有复评证据」「上一课没过就往下走」这类错。CI 每次都会跑。

## 5 分钟上手

### 使用者不需要装任何东西

| | |
|---|---|
| ❌ 不需要 Node.js / npm | 协议是纯 Markdown，没有构建步骤 |
| ❌ 不需要 Git | 下载 ZIP 解压一样用 |
| ❌ 不需要 API Key | 推荐的工具自带免费额度 |
| ❌ 不需要注册本项目 | 没有服务器、没有账号、没有订阅 |
| ✅ 只需要 | 一个能打开文件夹的 AI 工具 |

### 五步走

- [ ] **1. 装一个 AI 工具** —— 推荐 [Trae](https://www.trae.cn)：免费、中文、图形界面、无需 API Key

  打开官网 → 下载 Windows 版 → 双击安装 → 手机号/微信登录

  其它可选：**ZCode**（智谱，原生认 `AGENTS.md`，零配置）、**CodeBuddy**（腾讯）、**Qoder**（阿里）、**Cursor**

- [ ] **2. 打开文件夹** —— `文件 → 打开文件夹` → 选中 `StepsToGreat`

  > ⚠️ 打开的是**文件夹本身**，不是里面的某个文件。选错这一步，AI 读不到规则，后面全部无效。

- [ ] **3. Trae 用户：开一个开关** —— `设置（齿轮）→ 规则 → 导入设置 → 打开「将 AGENTS.md 包含在上下文中」`

  > 这一步 **90% 的人会漏**。其它工具大多零配置。

- [ ] **4. 说第一句话**

  ```
  我是学生，请先读 AGENTS.md，然后开始。
  ```

- [ ] **5. 验证它读到了** —— 问它：

  ```
  请复述 AGENTS.md 里「硬规则」那部分，有几条？
  ```

  正确回答是 **12 条**（口径以 `AGENTS.md` 第 2 节实际编号为准，`npm run check` 会自动核对）。答不出 → 回第 2、3 步检查。

## 学习规则（可以改成你自己的）

框架自带一套默认教学规则，但**规则不是写死的** —— 你可以全部改掉。

**怎么改？** 三种方式，任选：

| 方式 | 怎么做 |
|---|---|
| **直接改** | 编辑 [`我的学习/我的规则.md`](./我的学习/我的规则.md) |
| **口头说** | 对导师说「以后每轮只出 1 题」→ 它帮你写进去 |
| **不改** | 全用默认规则，也没问题 |

### 可以改什么

| 可改的 | 默认值 | 例子 |
|---|---|---|
| **每轮出几题** | 1–3 题 | 「每轮只出 1 题，我节奏慢」 |
| **一课总题量** | 约 5 题 | 「一课 3 题就够了」 |
| **纠错风格** | 先讲原理再给答案 | 「直接给我正确答案，别绕」 |
| **代改范围** | 笔误/语法直接改，概念错引导 | 「所有错都直接帮我改」 |
| **教学语言** | 跟学生走 | 「一律用中文」 |
| **语气 / emoji** | 耐心、克制 | 「别用 emoji」 |
| **个人偏好** | 无 | 「我讨厌长篇大论，控制在 200 字内」 |
| **目标与时间约束** | 无 | 「每天最多 30 分钟」 |

### 为什么规则能改，但框架文件不能改

| 文件 | 你能改吗 | 为什么 |
|---|---|---|
| [`我的学习/我的规则.md`](./我的学习/我的规则.md) | ✅ **随便改** | 你的规则，优先级最高，`git pull` 不会覆盖 |
| `协议/` `学科包/` `模板/` `_tools/` | ❌ 只读 | 框架本体。改了会和框架更新冲突，而且**规则会漂移** |

**设计原理**：改规则的正确位置是「**覆盖层**」，不是「改源码」。
你的规则单独存一份，优先级高于框架默认 —— 这样你既完全自由，又能随时 `git pull` 拿到框架更新。

### 规则优先级

冲突时，上面的赢：

```
1. 我的学习/我的规则.md        ← 你的规则，最高
2. 你当场说的话
3. 我的学习/00-学习档案.md 🚦   ← 当前进度（状态）
4. 协议/00_导师协议.md          ← 框架默认
5. 学科包/<学科>.md             ← 学科评估口径
```

> **一个建议**：`三维全 ✅ 才推进` 这条建议保留。
> 它是本项目的核心机制 —— 改成「差不多就行」，项目就退化成一个普通聊天助手了。
> 当然，那是你的选择；但改了之后，你就知道代价是什么。

## 只想要「装一次、到处用」？有 skill 版

本项目是**文件夹形态**：把文件夹用 AI 工具打开，它就变成导师。这是最省事的用法 —— 不用装任何东西。

但文件夹形态有三个绕不开的边界，**都是形态造成的，不是协议造成的**：

| 文件夹形态的边界 | 表现 |
|---|---|
| 规则**跟着仓库走** | 换个项目就得重新丢一次文件夹 |
| 触发靠**工具认不认 `AGENTS.md`** | 25 个跳板文件覆盖 28+ 工具，仍要一个个维护 |
| 内容**手抄会漂移** | 规则改一处、副本忘一处 |

**同一套协议还有一个 skill 封装版**：[**Steps2Great-skill**](https://github.com/wildcat430524/Steps2Great-skill) ——
装一次进 skills 目录，所有项目、所有会话都能触发。

| | **StepsToGreat**（本仓库） | [Steps2Great-skill](https://github.com/wildcat430524/Steps2Great-skill) |
|---|---|---|
| 形态 | 一个文件夹（打开它就是导师） | 一份 Agent Skill（装进任意支持 skills 的客户端） |
| 安装 | **不需要装任何东西** | 一行 `npx skills add wildcat430524/Steps2Great-skill` |
| 触发 | `AGENTS.md` + 25 个工具跳板 | frontmatter `description`（中英双语触发词） |
| 内容 | 仓库本体 | **镜像**本仓库 + 手写的 `SKILL.md` |
| 适合 | 想「一个文件夹带走全部」、想读全部设计文档 | 想「装一次到处用」、想分发 / 团队共用 |
| 数据 | 你的文件夹 | 你的工作区 —— **都是纯 Markdown，可以互相接续** |

**两者是同一套协议的两个壳**：本仓库改了教学规则，skill 那边跑一次
`node _build/sync-from-upstream.mjs` 就同步过去 —— 不手抄，所以不漂移。

> **怎么选**：日常自学、想省事 → 用**本仓库**（打开文件夹就能用）。
> 已经习惯用 Claude Code / Cursor / Codex 这类客户端、想「装一次哪都能用」→ 用 **[skill 版](https://github.com/wildcat430524/Steps2Great-skill)**。
> 两者可以同时用，学习记录就是普通 Markdown，换个壳接着学没问题。

## 常见问题

**换 AI 工具会丢记录吗？**
不会。全部数据是普通 Markdown，在 `我的学习/` 里。换工具 → 打开同一个文件夹 → 说「继续」。

**要花钱吗？**
协议本身免费。AI 工具大多有免费额度（Trae 国内版每月 500 积分）。协议文件是纯 Markdown，没有服务器、没有账号、没有订阅。

**要懂技术吗？**
不用。会「打开文件夹」和「打字」就够了。**使用者不需要装 Node / npm / Git。**

**能把一整本书丢进去学吗？**
能，这是最常用的用法。把书放进 `资料/`，说「我要学透它」，导师会先追问目标与投入时间，
再按书里**实际的章节**拆成一课一课；每课讲完就出题、你答完说「完成了」、三维评估通过才推进下一课。
进度落盘，学不完下次说「继续」。见 [想学透一本书 / 一份资料](#想学透一本书-一份资料发给-ai它一步一步教你)。

**AI 会不会瞎编书里的内容？**
它**不会给你一份查不到的书单** —— 协议禁止凭记忆教学（`AGENTS.md` 硬规则第 8 条）：
教学内容要么来自你放进 `资料/` 的文件，要么能说出具体可核实的一手来源，引用要精确到「出自哪份文件的哪一节」。
资料**读不出来**（扫描件 / 加密 / 公式乱码）时，协议要求它**明确停下**告诉你缺什么，而不是凭印象补课。

> ⚠️ **诚实边界**：协议能约束行为，但不能保证模型零幻觉。
> 遇到关键结论，建议你回原文核对 —— 可以这样问它：
> `这个结论我在资料里找不到。请指出具体文件、章节和原文；找不到就撤回它并说明不确定。`

**我的资料会被上传吗？**
**可能。** 这取决于你用的工具，本项目无法替你控制：

| 工具类型 | 文件是否上传 | 云端索引 / 日志 | 适合敏感资料 |
|---|---|---|---|
| 本地模型（Ollama / Zed / goose） | 通常否 | 本地 | ✅ 较适合 |
| 云端 Agent（Trae / CodeBuddy / Cursor…） | 通常是 | 通常有，保留策略由厂商定 | ⚠️ 谨慎 |

- 已知情况（**截至 2026-09，以各厂商最新说明为准**）：Trae 索引时会临时上传文件做 embedding；CodeBuddy / WorkBuddy 个人版内容会过腾讯云。
- **敏感资料**（病历、内部文档、个人信息）建议用本地模型，或先脱敏。

> **删除边界**：删掉本地文件夹**只删掉你本地的那一份**。
> 工具侧的会话记录、索引缓存、日志保存在厂商那里，需要在对应工具里单独删除。

**AI 判错了怎么办？**
直接说「我觉得这题你判错了，理由是…」。协议**明确允许学生质疑**，摸底结论不认同时以学生为准。

**能同时学好几科吗？**
能，但要按规矩来：**一次只有一个「当前学科」**，切换前先把当前这一轮收尾；
其他学科的进度记在 📚 索引进度列的「状态」里，课次号带学科前缀（`Python #2`）。
完整流程见 [`协议/03_落档事件表.md` 第 7 节](./协议/03_落档事件表.md#7-多学科并行-是当前不是全部)。

**能离线用吗？**
协议本身完全离线。但「导师」是 AI，需要模型 —— 可用本地模型（Ollama）做到全程不联网。

**怎么贡献一个新学科包？**
复制 [`学科包/_自定义学科包模板.md`](./学科包/_自定义学科包模板.md)，填 7 个部分。**最缺的是：乐器、健身、绘画、写作、软件操作**。

**三维评估为什么非得三个维度？合成一个「综合分」不行吗？**
不行，那会丢掉这个项目最核心的信息。三个维度分开，才能分清「**懂了但手滑**」和「**根本没懂**」——
前者直接代改就过去了，后者必须走苏格拉底引导。合成一个分数，两者看起来都是「60 分」，处理方式却完全相反。

**判一个错属于哪一维，我也拿不准怎么办？**
按 [`协议/00_导师协议.md` §3 的裁决口诀](./协议/00_导师协议.md)：**说错了 → ①；想错了 → ②；写错了 → ③**；
同时命中两维按更靠前的判。这条口诀是 8 份学科仿真的直接产物 —— 当时 6 个学科的核心症状都是「判不出来」。

**规则能改，那我把「全 ✅ 才推进」改成「差不多就行」行不行？**
技术上完全可以（写进 `我的学习/我的规则.md` 即可，优先级最高）。
但**改了之后项目就退化成一个普通聊天助手了** —— 这条是本项目的核心机制，不是可选项。你的选择，代价先说清楚。

**我怎么知道协议有没有被遵守？**
跑状态校验器，它按 [`协议/04_状态机.md`](./协议/04_状态机.md) 的 12 条不变式检查你的学习档案：

```bash
node _tools/validate-state.mjs --root .            # 校验你的工作区
npm run verify                                     # 框架自检全跑一遍（5 个检查器）
```

它能查出「标了已掌握却没有复评证据」「上一课没过就往下走」「同一份文档两份复评区」这类错。CI 每次都会跑。

**你们怎么保证这些规则真的有用，而不是一堆纸上谈兵？**
四类实测证据，全部在仓库里可查：8 份学科仿真、弱模型当探针、端到端跑测、状态校验器 + 19 组回归用例。
见 [「这套规矩是怎么来的」](#这套规矩是怎么来的不是拍脑袋是实测出来的)。

**我用的工具不支持打开文件夹（比如网页版 Chat）怎么办？**
试试 [skill 版](https://github.com/wildcat430524/Steps2Great-skill) —— 它给支持 Agent Skills 的客户端用；
如果那个客户端也不支持，那就只能把 `AGENTS.md` 的内容手工粘进对话（会丢掉「按需读取」和「状态落盘」两个优势）。
