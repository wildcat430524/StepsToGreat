# 02_新课模板（Lesson Template）

> 用途：每次发布新课，照本文件产出两个文件：`01_教学引导.md`（导师写）+ `01_学生回答.md`（镜像同题，学生作答 + 最终复评）。
> 英文版：[`02_新课模板.en.md`](./02_新课模板.en.md)

---

## 1. 两个文件的关系（唯一真相原则）

```
学科/<学科>/NN-<课名>/
├── 01_教学引导.md     ← 导师写：讲解 + 例题 + 题目（按轮次排布）
└── 01_学生回答.md     ← 学生写：镜像同题 + 空答案位 + 末尾两个占位区
```

- **回答文档 = 唯一学习证据**。是否掌握，以回答文档的「最终复评结果」为准。
- **不生成 HTML 副本**。需要交互练习时再按需生成，且生成物不算真相（Markdown 才是）。
- 回答文档末尾固定两个占位 H2：`## 最终复评结果`、`## 正确答案与解析` —— 评估完成后由导师填写。

---

## 2. 教学引导文档骨架（8 段，顺序固定）

```markdown
# <学科> | NN_教学引导

## 一、为什么要学这个？
<1–2 段，必须绑定学生的目标。不许写"这是基础很重要"这种空话。>

## 二、核心概念
<这个知识点是什么、为什么、怎么用。一次只讲 1–2 个概念。>

## 三、语法 / 方法 + 示例
<最小可运行（或可操作）的示例，逐行/逐句讲清。>

## 四、新旧对比
<和已经学过的东西对比：以前怎么做，现在怎么做，区别在哪。>

## 五、常见陷阱
<学生最容易错的 3–4 处，写清"为什么错"和"错了会怎样"。>

## 六、和之前知识的关联
<把它挂到已学的知识网络上。>

## 七、本节重点（5 条）
<5 条，学生复习时只看这里。>

## 八、题目（按轮次排布）

> **每轮只出 1–3 题。** 导师**一次只发一轮**，学生答完并评估通过后，才发下一轮。
> 不要一次把下面的题目全发出去，也不要在文档里让"一次全部作答"。

### 第一轮：概念理解（1–2 题）
### 第二轮：动手实操（2 题）
### 第三轮：综合应用（1 题）
```

> **为什么按轮次排**：如果第 1 题就暴露概念错误，一次发 5 题会让后面几题**跟着全错**；
> 一轮一轮来，第 2 题就是在正确理解上做的。总题量不变，但每一题都在正确轨道上。

---

## 3. 出题纪律

| 项 | 规则 |
|---|---|
| **每轮题量** | **1–3 题**（默认 2 题；知识点全新或较难时出 1 题） |
| **一课总轮数** | 通常 2–3 轮（合计约 5 题）；可按学生目标调整，不固定 |
| **发下一轮的前提** | **本轮全 ✅**。本轮有 ⚠️/❌ → 先走完「讲解 → 代改/自改 → 复评」再发 |
| **变式** | 实操题与综合题必须在例题基础上**变化条件**（换数据、换约束、加边界），**不能与例题同构照抄** |
| **语言** | 用学生的语言出题 |
| **禁止** | 一次发出超过 3 题；把整课题目一次列全让学生自己做完；出「请复述第 3 节内容」这种考记忆的题 |

---

## 4. 回答文档模板（**按轮次追加**，不是一次列全）

> ⚠️ **关键**：回答文档**初始只放第一轮的题目**。学生答完、评估通过后，
> 导师再**追加**下一轮的题目（只增不改，学生已写的部分原样保留）。
>
> 这样做的原因：文档里如果一次列全 5 题，学生等于看到了全部题目 —— 与「一轮 1–3 题」的设计相矛盾。

**第一轮（发课时写入）**：

```markdown
# <学科> | NN_学生回答

## 主题：<本课知识点>

## 第一轮 · 问题 1：<题面复述>
**你的回答：**
```
（在此作答）
```

## 第一轮 · 问题 2：<题面复述>
**你的回答：**
```
（在此作答）
```
```

**第二轮（第一轮全 ✅ 后，追加）**：

```markdown
---

## 第二轮 · 问题 3：<题面复述>
**你的代码 / 你的作答：**
```
（在此作答）
```

## 第二轮 · 问题 4：<题面复述>
**你的代码 / 你的作答：**
```
（在此作答）
```
```

**第三轮（第二轮全 ✅ 后，追加）**：

```markdown
---

## 第三轮 · 问题 5：<题面复述>
**你的代码 / 你的作答：**
```
（在此作答）
```
```

**末尾（初始就放好，评估完成后由导师填）**：

```markdown
---

## 最终复评结果
（整课所有轮次通过后由导师填写）

---

## 正确答案与解析
（整课所有轮次通过后由导师填写）
```

## 5. 发布新课时对学生的输出模板

```markdown
# #NN <上一课名> 已闭环 ✅            ← 若上一课刚通过
**复评结果**：概念、逻辑、规范全部通过。
首次评估发现 N 处问题，已按你的要求直接代改：1)… 2)… 3)…
学习档案也已同步更新。
---
**下一步：#NN <新课名>**（<一句为什么值得学，绑定你的目标>）
### 📁 文档位置
- 教学引导：<路径>
- 回答文档：<路径>
### 📖 本课重点（5 条）
### 📚 配套阅读
- 必读：<篇目> §<章节号> <章节名>（课前读 / 课后对照 / 自测来源）
- 选读：<篇目> §<章节号> <章节名>（什么时候再回来看）
- 本课自测来源：<篇目> §<自测题章节>
### ✅ 你的任务
阅读完教学引导后，在回答文档里完成**本轮题目**（1–3 题），然后告诉我"完成了"即可。
> 复习触发提醒（不阻塞）
```

## 6. 落档（发布新课那一刻）

| 要做的 | 位置 |
|---|---|
| 新建 `01_教学引导.md`（题目按轮次排布，但**只发第一轮**） | `学科/<学科>/NN-<课名>/` |
| 新建 `01_学生回答.md`（**只放第一轮题目** + 末尾两个占位区） | 同上 |
| 追加后续轮次题目 | 在回答文档里**追加**（只增不改） |
| 更新当前课次与进度 | `我的学习/00-学习档案.md` → 🚦 交接状态 |
| 追加课次映射 | 同上 → 📚 课次索引 |
