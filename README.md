## 开始

**不用先读长文档，也不用背规则条数。** 三件事：

| # | 做什么 | 你会看到 |
|---|---|---|
| **1** | 用能读写本地文件的 AI 工具打开这个文件夹 | 让工具读取根目录的 `AGENTS.md` |
| **2** | 说一句：`请先读 AGENTS.md。我想学 <X>，目标是 <Y>，每天大约 <Z> 分钟。` | 缺失需求一次补齐，已有信息不重复问 |
| **3** | 回答场景里的第一个小问题 | 一句话、一个判断或一步操作；卡住时缩小问题，不要求先装软件或写整道大题 |

之后你的日常只有两个动作：**回答当前问题**，和**说一句「完成了」**。

> **可以直接在聊天里回答。** 进入正式学习后，导师把你的原答**原文整理**进回答文档，再重读评估；也可以自己在文档里作答。

## 学习视图：两层进度分开

每块内容先给一个两层视图，再开始讲。**模块掌握条**看的是「这个模块里正式掌握了几个知识单元」，**本次小目标清单**看的是「这一小块你具体学会了什么」——两者分开算，清单全勾，条也可以不动。

这是一个**虚构示意**（不是真实测评记录），展示小目标完成后的样子：

**Python 列表 · 模块掌握**

`▰▰▱▱▱▱▱▱▱▱` **1/4** 个知识单元已掌握

**小目标｜追加一件商品**

- [x] 说清 **`append`** 是把单个元素加到列表末尾
- [x] 区分**追加**与**覆盖**，知道原有元素会保留
- [x] 独立调用 **`append`** 新增商品，并核对列表变化

> **已完成**｜你现在能给已有清单追加商品，不用重写整张清单。可以停在这里。

*依据：模块—认识列表最终复评；技能—本次正式评估。添加单元尚未全部掌握，模块条保持 1/4。*

三条规矩值得记住：

- **证据达标才勾**：导入中的表现只记「初步观察」；提示下答对会标明提示，独立技能项不勾。
- **及时具体反馈**：每个实质进展先说你刚独立做对了什么、产生了什么效果，再纠错或给下一步。
- **有自然停点**：小目标完成就说清「你现在能……」，不顺手加下一块必做题。

口径全文见 [小目标进度](./协议/06_小目标进度.md) 与 [对话导入](./协议/05_对话导入.md)。

## 核心规则摘要

| 规则 | 一句话 |
|---|---|
| **三维评估** | ① 概念理解 / ② 逻辑正确 / ③ 规范表达，**适用维度全部通过**才推进；不适用的标 `— 不适用` |
| **一轮 1–3 题** | 本轮通过才发下一轮，**绝不一次把一课的题全发** |
| **重读再评估** | 你说「完成了」→ 导师**重新读回答文档**，禁止凭对话记忆判定 |
| **小改大导** | 笔误/语法直接帮你改并讲透三段式；概念、逻辑错走引导，让你自己推 |
| **裁决口诀** | 说错了 → ①；想错了 → ②；写错了 → ③ |
| **费曼诊断** | 大模块收尾做一次，一课最多一次；你说不想讲就换普通题 |
| **状态只在三处** | 🚦 交接状态 / 📊 掌握表 / ⏳ 待办表，不重复记 |

> 完整机制、三个状态区的由来、费曼法的硬性约束，见 [核心机制全文](./docs/readme-details.md#核心机制全文)。

## 安装

**教学协议本身不需要运行环境**：Node、npm 与检索脚本都是**可选**工具。你需要的只是一个能读写本地文件的 AI 工具。

- [ ] **1. 装一个 AI 工具** —— 例如 [Trae](https://www.trae.cn) 或你已在用的支持文件读写的工具（账号、套餐以工具官方说明为准）
- [ ] **2. 打开文件夹** —— `文件 → 打开文件夹` → 选中 `StepsToGreat`（**是文件夹本身，不是里面的某个文件**）
- [ ] **3. Trae 用户开一个开关** —— `设置 → 规则 → 导入设置 → 打开「将 AGENTS.md 包含在上下文中」`
- [ ] **4. 说第一句话** —— `我是学生，请先读 AGENTS.md，然后开始。`
- [ ] **5. 开始回答第一个小问题** —— 不必先考规则条数

> 需要排查加载时，可以让它复述「硬规则」有几条（当前 **12 条**）—— 但那只是排查线索，**不能证明规则生效**；优先核对文件读取轨迹与实际产出。
> 📖 [五分钟上手](./教程/01-五分钟上手.md)｜🧰 [各工具接入](./教程/02-各工具接入指南.md)｜🖼 [界面示意](./教程/界面示意图.md)｜📋 [兼容矩阵](./docs/AGENT-COMPAT.md)
> 升级框架或迁移档案见 [`docs/UPGRADE.md`](./docs/UPGRADE.md)。

## 用你自己的资料教

**这是最常用的用法**：把书或资料丢进 [`资料/`](./资料/)，说一句「我要学透它」，AI 负责拆课、讲课、出题、批改、记进度。

导师必须**先定位、再完整读该小节**（含条件与例外），引用写成「出自 `<文件名>` 第 N 节」，可附行号与版本指纹。
**读不了的内容不算依据**：扫描件、加密文件需要先 OCR 或文字提取，读不出来时导师会**明确停下**说明缺什么，不许凭印象补课。
没有现成教材时，导师依据**可核实的一手来源**讲解，并把来源写进教学文档。

| 格式 | 支持度 |
|---|---|
| `.md` `.txt` | ✅ 最好 |
| `.pdf`（文字版） | ✅ 好（扫描件需 OCR） |
| `.docx` `.pptx` | ⚠️ 一般，建议另存为 `.md` |
| 图片 / 视频 | ⚠️ 看工具；视频请给字幕或笔记 |

> 一次放一份、只增不改、标注来源：[`资料/README.md`](./资料/README.md)｜检索与引用方法：[`docs/material-retrieval.md`](./docs/material-retrieval.md)

## 同一套协议的两个壳

| | **StepsToGreat**（本仓库） | [Steps2Great-skill](https://github.com/wildcat430524/Steps2Great-skill) |
|---|---|---|
| 形态 | 一个文件夹，打开它就是导师 | 一份 Agent Skill，装进支持 skills 的客户端 |
| 安装 | **无需项目运行环境**，另需 AI 工具 | 一行 `npx skills add wildcat430524/Steps2Great-skill` |
| 触发 | `AGENTS.md` + 自动生成的工具跳板文件 | frontmatter `description`（中英双语触发词） |
| 数据 | 你的文件夹 | 你的工作区 —— 都是纯 Markdown，**可以互相接续** |

两边是**同一套教学协议**：本仓库改了规则，skill 那边跑一次 `node _build/sync-from-upstream.mjs` 同步过去（`SKILL.md` 是手写入口，单独维护）。

> 想「装一次到处用」，用 [skill 版](https://github.com/wildcat430524/Steps2Great-skill)；日常自学、想省事，就用本仓库。

## 常见问题

**换 AI 工具会丢记录吗？**
不会。全部数据是普通 Markdown，在 `我的学习/` 里。换工具 → 打开同一个文件夹 → 说「继续」。

**要花钱吗？**
协议本身免费，是纯 Markdown。AI 工具的登录、免费额度与费用由提供方决定，可能随时间变化。

**要把答案写进文件吗？**
不必。可以在**聊天里回答**，导师把你的原答**原文追加**进回答文档再重读评估；没落盘的内容不保证换会话接续。

**AI 会不会瞎编书里的内容？**
协议禁止凭记忆教学（硬规则第 8 条）：要么来自你放进 `资料/` 的文件，要么能说出具体可核实的一手来源，引用精确到小节。

**能同时学好几科吗？**
能，但**一次只有一个「当前学科」**，切换前先把当前轮收尾。见 [`协议/03_落档事件表.md`](./协议/03_落档事件表.md)。

**规则能改吗？**
能，写进 [`我的学习/我的规则.md`](./我的学习/我的规则.md) —— 覆盖层，优先级最高，不用改框架。
