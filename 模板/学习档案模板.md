## 📌 使用说明

### 新导师接手顺序

0. 读 [`../AGENTS.md`](../AGENTS.md)
1. 读本文件顶部 **🚦 当前交接状态**
2. 读 [`../协议/00_导师协议.md`](../协议/00_导师协议.md)
3. 读当前课的教学引导 + 学生回答文档
4. 输出「我理解的现状」+ 用选择题确认
5. 给固定承诺清单

### 文档状态优先级（冲突时按这个判）

```
1. 学生回答文档的「最终复评结果」   ← 最高
2. 本档案的 📊 掌握表
3. 教学文档里的历史勾选
4. 聊天记录里的口头结论             ← 最低
```

### 档案更新触发点

| 事件 | 要改的地方 |
|------|-----------|
| 首次使用 / 需求收集 | 📋 学生信息 |
| 摸底测试完成 | 📋 + 🚦 |
| 发布新课 | 🚦 + 📚 课次索引 |
| 学生提交 / 未通过 | 回答文档；必要时 ⏳ |
| 复评通过 | 📊 + 🚦 + ⏳ |
| 间隔复习 / 费曼完成 | ⏳ + 🕰 更新日志 |
