# 轮次教学引导模板

> 发布每一轮时复制为 `NN-<课名>/第N轮_教学引导.md`。本文件保存该轮完整讲解、例子、可核对来源与 1–3 道题；后续轮次新建文件，不改写已发布轮次。

```markdown
# <学科> · <课名>｜第 N 轮教学引导

> [教学总入口](01_教学引导.md) · [学生回答](01_学生回答.md)

## 要解决的问题

<承接本轮场景，说明要解决什么。>

## 方法与例子

<讲清本轮关键原理、步骤和必要例子，标出可核对来源。>

## 容易弄错的地方

<必要时写 1–2 处；没有则删除此节。>

## 本轮练习

### 第 N 轮

**问题 X**：<完整题面；本轮总共 1–3 题。>
```

本轮题面须与 `01_学生回答.md` 中对应轮次一致。总入口只维护导航与当前展示区；学生原答、修订和评估都留在回答文档。正文用主题和轮次标识，正式课次号留在学习档案索引。
