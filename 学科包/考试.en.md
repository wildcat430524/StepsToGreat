# Subject Pack · Exam Prep

> Applies to: study **whose goal is passing a specific exam** — postgraduate entrance exams, civil service exams, certification exams (teaching credential / bar exam / CPA / IELTS / TOEFL…).
> **This pack is a "meta-pack"**: it defines the assessment criteria specific to exam taking and is normally used **stacked with a content subject pack**.
> Example: postgraduate math = `理科.md` (content) + this pack (exam prep); civil service aptitude test = `文科.md` + this pack.
> Chinese version: [`考试.md`](./考试.md)

---

## 1. Three-dimension definitions (exam-prep version)

| Dimension | Name | What it judges | What a typical ✅ looks like |
|---|---|---|---|
| ① | **Knowledge mastery** | Whether the tested point itself is understood | Can state the definition of this tested point and its common variations |
| ② | **Correct problem-solving** | Whether they can get it right, and whether the method is the **optimal path** | The answer is right, and the solution suits the time pressure of the exam room |
| ③ | **Answer format** | Whether it matches the **exam's scoring standard** | Subjective answers hit all the scoring points, objective answers have no bubbling errors, time is allocated sensibly |

> In an exam setting, ② carries an extra requirement: **not just "right" but also "fast"**. Using a slow method that happens to score is the same as losing marks in the exam room.

---

## 2. Dimension ③ criteria (specific to exam prep)

### ❌ Structural errors (must lose points)

- **Subjective answers miss scoring points** (the answer is right but the scoring points aren't written, e.g. a politics essay with no "principle + material analysis" structure)
- **Wrong answer format** (an essay with no title, a policy essay with no bullet points, a calculation with no "Solution:")
- **Wrong time strategy** (spending 3× the time on one question, so later questions you could do go undone)
- **Wrong answer order** (doing the hard questions before the easy ones)
- **Bubbling / filling-in errors** (objective answers off by one row)
- **Word count over or under** (policy essays and compositions have hard word counts)

### ⚠️ Exemptable (no points lost)

- Sloppy but legible handwriting
- Working written on the answer sheet (if that exam allows it)
- Abbreviated calculation steps (if that exam only looks at the final answer)
- Wording different from the standard answer but the same in meaning (**subjective marking looks at scoring points, not phrasing**)

## 3. Teaching points specific to exam prep

| Point | Explanation |
|---|---|
| **Real papers first** | All practice is based on real past papers; mock papers second; textbook examples last |
| **Time awareness** | Every question is tagged with a "suggested exam-room time"; going over is itself a problem |
| **Scoring-point awareness** | Subjective answers must be trained on "how many points to write, how many words per point" |
| **Error attribution** | Wrong answers must be classified: didn't know / knew but got it wrong / knew but was slow — three different remedies |
| **Repetition rate** | High-frequency tested points from real papers must be drilled until "you see the question and know what it tests" |
| **Triaging strategy** | Decide explicitly which questions to abandon (this is the key to raising your score) |

---

## 4. Question forms

| Round | Question type | Key points |
|---|---|---|
| Round 1 | **Tested-point recognition** (1–2) | "Which tested point does this past-paper question test? What other variations exist?" |
| Round 2 | **Timed practice** (2) | Must **give a time limit** (e.g. "within 5 minutes") and check whether it was exceeded |
| Round 3 | **Subjective scoring points** (1) | Write the answer + mark how many scoring points you hit |

> **Send only 1–3 questions per round, and send the next round only when this round is all ✅** (see §2 of `协议/00_导师协议.md`).
> This matters especially for exam prep: **never send a whole paper at once** — that turns into drilling, not teaching.

**A good exam-practice question**: take a real past-paper question directly; don't make one up (made-up questions have no reliability).

---

## 5. Verification methods

1. **Timed reproduction**: the same question, done correctly within the set time
2. **Self-scoring**: against the marking standard, count how many points you hit yourself
3. **Variation recognition**: reword this tested point — can you still recognise it?
4. **Triage judgement**: in the exam room, should you do this question or skip it? Why?
5. **Error attribution**: which class does this mistake fall into — "didn't know / knew but wrong / knew but slow"?

> The exam-prep standard for "mastered" is: **you can still score steadily under exam-room time pressure**.

## 6. How to write the stacking with a content subject pack

```markdown
> This subject uses: `学科包/理科.md` (content dimensions) + `学科包/考试.md` (exam-prep dimensions)
> For assessment, dimension ① follows the science criteria, dimension ② adds "is this the optimal solution",
> and dimension ③ is judged by this pack's "answer format" (scoring points / format / time).
```

Write this into 📋 Student Info of `我的学习/00-学习档案.md`, so the criteria stay consistent when a different tutor takes over in a later session.

## 7. How to write further reading

Exam-prep material must be precise down to **past-paper year + question number**:

```markdown
### 📚 Further reading
- Required: <past-paper book> <year> <subject> question <N> (do it timed, then check the answer)
- Required: <textbook> chapter <N> <tested point name> (fill the gap)
- Optional: <past-paper book> <year> question <N> (a variation of the same type; when to do it again)
- Self-test source for this lesson: <past-paper book> <year> questions <N>–<M>
```
