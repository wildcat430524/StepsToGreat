# 学生回答模板（Student Answer Template）

> 复制为 `NN-<课名>/01_学生回答.md`，**题目与教学引导镜像同题**。
> 本文件是**唯一学习证据** —— 是否掌握，以本文件的「最终复评结果」为准。
> ⚠️ **按轮次追加**：初始只放第一轮的 1–3 题；学生答完、本轮全 ✅ 后，再追加下一轮。

---

**第一轮（发课时写入）**：

```markdown
# <学科> | NN_学生回答

## 主题：<本课知识点>

## 第一轮 · 问题 1：<题面复述>
**你的回答：**
```
（在此作答）
```

## 第一轮 · 问题 2：<题面复述>
**你的回答：**
```
（在此作答）
```
```

**第二轮 / 第三轮（上一轮全 ✅ 后，追加）**：

```markdown
---

## 第二轮 · 问题 3：<题面复述>
**你的代码 / 你的作答：**
```
（在此作答）
```
```

> 依此类推。**不要一次把 5 题都写进去** —— 那样学生等于看到了全部题目，
> 与「一轮 1–3 题、边纠正边推进」的设计相矛盾。

**末尾（初始就放好，整课通过后由导师填）**：

```markdown
---

## 最终复评结果
（整课所有轮次通过后由导师填写）

---

## 正确答案与解析
（评估完成后由导师填写）
```

---

## 纪律

| 规则 | 说明 |
|---|---|
| **只增不改** | 学生写过的答案永远不覆盖；评估结论追加在下方 |
| **按轮次追加** | 初始只放第一轮题目；上一轮全 ✅ 后才追加下一轮 |
| **空围栏即未答** | 围栏内为空 = 尚未作答，导师不发评估 |
| **末尾两区占位** | `最终复评结果` / `正确答案与解析` 由导师在**整课通过后**填写 |
| **优先于教学文档** | 本文件的最终复评结论，优先于教学引导里的历史勾选 |
