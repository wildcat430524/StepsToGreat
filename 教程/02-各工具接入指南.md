# 02 · 各工具接入指南

> 本文覆盖 **25+ 个 AI 工具**的接入方式。核心结论：**本项目只维护一份规则（`AGENTS.md`），其余文件都是自动生成的跳板。**
> 你用什么工具都行 —— 只要它能打开文件夹。

---

## 0. 一句话原理

```
你的 AI 工具
    ↓ 读取（各工具认的文件名不同）
跳板文件（CLAUDE.md / CODEBUDDY.md / .trae/rules / …）
    ↓ 全部指向
AGENTS.md  ← 唯一真相
    ↓ 指引到
协议/00_导师协议.md + 学科包/ + 我的学习/
```

**为什么这样设计**：如果每个工具都复制一份完整规则，改一处就要改 25 处，必然漂移。
现在改规则只改 `AGENTS.md`，跳板文件用 `node _tools/setup-agents.mjs` 一键重生成。

## 2. 非技术用户首选：Trae（推荐）

**为什么推荐**：免费、全中文、图形界面、Windows 可用、不需要 API Key / Node.js / Git。

### 安装步骤

| 步 | 做什么 | 截图 |
|---|---|---|
| 1 | 浏览器打开 `https://www.trae.cn` | `图片/trae-01-官网.png` |
| 2 | 点「下载」→ 选 Windows → 下载 `.exe` | `图片/trae-02-下载.png` |
| 3 | 双击安装，一路「下一步」 | `图片/trae-03-安装.png` |
| 4 | 打开 Trae，手机号 / 微信扫码登录（**不需要信用卡**） | `图片/trae-04-登录.png` |
| 5 | `文件 → 打开文件夹` → 选中 `StepsToGreat` 文件夹 | `图片/trae-05-打开文件夹.png` |
| 6 | **设置（齿轮）→ 规则 → 导入设置 → 打开「将 AGENTS.md 包含在上下文中」** | `图片/trae-06-开关.png` |
| 7 | 新建对话，输入「我是学生，请先读 AGENTS.md，然后开始。」 | `图片/trae-07-对话.png` |

> ⚠️ **第 6 步是最容易漏的一步。** Trae 默认不读 `AGENTS.md`。
> 本项目已在 `.trae/rules/` 放了 `alwaysApply: true` 的跳板，所以忘了开也能用，但建议开。

### 验证是否生效

```
请复述 AGENTS.md 里「硬规则」那部分，有几条？
```

正确回答是 **9 条**。答不出 → 回到第 5、6 步。

## 3. 原生零配置首选：ZCode（智谱）

**为什么值得用**：**原生读 `AGENTS.md`**，零配置，无需任何开关。

| 项 | 事实 |
|---|---|
| 厂商 | 北京智谱华章（智谱 / Z.ai） |
| 形态 | Electron 桌面 App + Web + 终端 CLI（`zcode`） |
| 免费 | 工具免费，**需自备 API Key 或套餐**（GLM Coding Plan / BigModel） |
| 新用户 | **5 天体验期**（额度页面数字不一致：500 万/天 vs 800 万/天） |
| Windows | ✅ x64 / ARM64 |
| 规则文件 | `AGENTS.md`（工作区根目录 + `~/.zcode/AGENTS.md`） |

### 接入步骤

1. 官网 `https://zcode.z.ai/` → 立即下载 → Windows x64 `.exe`
2. 双击安装（被防火墙/杀软拦截时加白名单）
3. 首次启动 → 左下角「连接使用」登录（连 Z.ai 或 BigModel，或填 API Key）
4. `打开文件夹` → 选 `StepsToGreat`
5. **规则自动生效**，无需任何设置
6. 验证：新建会话，让它复述硬规则

### ⚠️ ZCode 特有的三个坑

| 坑 | 说明 |
|---|---|
| **不扫子目录** | 只读工作区**根目录**的 `AGENTS.md`，子目录里的不读 → 本项目规则都在根目录，没问题 |
| **100 KB 截断** | `AGENTS.md` 超过 100 KB 会被截断（本项目远小于此） |
| **改规则需新开会话** | 已启动的会话不热更新 |

## 5. 如果你用网页版 AI（ChatGPT / Claude / 豆包 / Kimi）

**网页版不能打开文件夹**，所以：

1. 手动把 `AGENTS.md` 的内容**复制粘贴**到对话框
2. 再粘贴 `协议/00_导师协议.md`
3. 然后说「按上面的协议，我是学生，开始」

**缺点**：每次新对话都要重新粘贴，且 AI 无法读写你的文件（学习记录要你自己复制）。

**建议**：网页版只用来「试玩」，真正长期学习还是用能打开文件夹的工具。

## 6. 常见问题排查

| 症状 | 原因 | 解决 |
|---|---|---|
| AI 说找不到 AGENTS.md | 打开的是文件不是文件夹 | 重新「打开文件夹」 |
| AI 说不知道规则 | Trae 没开开关 | 设置 > 规则 > 导入设置 > 打开「将 AGENTS.md 包含在上下文中」 |
| AI 读到的规则不全 | ZCode 不扫子目录 / 超 100KB 截断 | 规则放根目录；本项目已满足 |
| AI 改了文件但下次会话忘了 | 工具不支持持久记忆 | 本项目靠 `我的学习/00-学习档案.md` 落盘，不靠 AI 记忆 |
| 额度很快用完 | 一次读了太多文件 | 让 AI **按需 read**，别一次塞 5–10 个 md |
| 中文长文档表现差 | 免费档多绑 Auto/弱模型 | 升级档位，或换 ZCode/Cursor |

## 7. 换工具会丢记录吗？

**不会。** 你的全部数据在 `我的学习/` 里，是普通 Markdown 文件：

```
我的学习/
├── 00-学习档案.md          ← 总状态
└── 学科/<学科名>/
    ├── 00-摸底测试.md
    ├── 00-课程路线.md
    └── 01-<课名>/
        ├── 01_教学引导.md
        └── 01_学生回答.md
```

换任何工具 → 打开同一个文件夹 → 说「继续」→ 它就接着教。

## 8. 自己加一个新工具

如果你的工具不在表里：

1. 查它的规则文件叫什么（官方文档搜 "rules" 或 "instructions"）
2. 编辑 `_tools/setup-agents.mjs` 的 `TARGETS` 数组，加一条
3. 跑 `node _tools/setup-agents.mjs`
4. 提 PR 到本项目，让下一个人不用再查

```js
{
  path: '.newtool/rules/00-steps-to-great.md',
  body: pointer('NewTool'),
}
```
