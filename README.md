## 这是什么

**不是软件，不是课程，是一个文件夹。**

里面全是 Markdown：一套教学协议 + 你的学习档案。
把它用 AI 工具打开，AI 就按协议当你的导师。

```
你：我是学生，请先读 AGENTS.md，然后开始。
AI：（读协议）→ 问你 3 个问题 → 摸底测试 → 定起点 → 发第一课
你：完成了。
AI：（重新读你的答案）→ 三维评估 → 帮你改错并讲透 → 落档 → 发下一课
```

## 5 分钟上手

### 1. 装一个 AI 工具

推荐 **Trae**（免费、中文、图形界面、无需 API Key）：

- 打开 `https://www.trae.cn` → 下载 Windows 版 → 双击安装 → 手机号/微信登录

其它可选：**ZCode**（智谱，原生认 AGENTS.md，零配置）、**CodeBuddy**（腾讯）、**Qoder**（阿里）、**Cursor**。

完整对比 → [`教程/02-各工具接入指南.md`](./教程/02-各工具接入指南.md)

### 2. 打开文件夹

```
文件 → 打开文件夹 → 选中 StepsToGreat
```

> ⚠️ 打开的是**文件夹本身**，不是里面的文件。

### 3. 说第一句话

```
我是学生，请先读 AGENTS.md，然后开始。
```

### 4. Trae 用户：开一个开关（重要）

```
设置（齿轮）→ 规则 → 导入设置 → 打开「将 AGENTS.md 包含在上下文中」
```

> 这一步 90% 的人会漏。其它工具大多零配置，见兼容矩阵。

### 5. 验证它读到了

```
请复述 AGENTS.md 里「硬规则」那部分，有几条？
```

正确回答是 **9 条**。

## 核心机制

### 三维评估 · 全 ✅ 才推进

每个知识点按三个**独立**维度评估：

| 维度 | 编程 | 英语 | 数学 | 文科 |
|---|---|---|---|---|
| ① 概念理解 | 懂不懂 | 理解 | 概念 | 理解 |
| ② 逻辑正确 | 算法/边界 | 表达达意 | 推导/计算 | 论证 |
| ③ 规范表达 | 语法可编译 | 语法规范 | 推导规范 | 表述规范 |

**三项全 ✅ = 掌握，才允许推进下一课。** 任意一项 ⚠️ 就继续练。

### 小问题导师直接代改

笔误、单点语法、缺符号这类小问题，AI **直接帮你改**，不让白答一轮 —— 但必须讲透三段式：

```
① 你的原答案 → ② 错在哪、为什么（讲原理）→ ③ 我改成了什么
```

大问题（概念错、逻辑不通）仍走苏格拉底式引导，让你自己推导。

### 状态只写在三个地方

| 位置 | 回答什么 |
|---|---|
| 🚦 当前交接状态 | 现在这一课是什么 |
| 📊 掌握表 | 哪些算真掌握 |
| ⏳ 待办表 | 有什么挂起 |

所以你**随时关掉、随时回来**都能接上。

## 目录结构

```
StepsToGreat/
├── AGENTS.md                    ← 唯一契约（AI 从这里开始）
├── AGENTS.en.md                 ← 英文版
├── 协议/                         ← 教学规则（怎么评估、怎么代改、怎么发课）
├── 学科包/                       ← 各学科的评估口径
├── 模板/                         ← 档案 / 路线 / 摸底 / 教学 / 回答 的空模板
├── 示例/                         ← 5 分钟跑通全流程的演示
├── 教程/                         ← 上手 / 接入 / 设计说明
├── _tools/                       ← 质检 + 跳板生成脚本
├── docs/                         ← 兼容矩阵 + 架构决策记录
├── 我的学习/                     ← 【你的数据】全部记录在这里
└── 资料/                         ← 【你的资料】放这里，AI 会读
```

**框架与数据分离**：`我的学习/` 和 `资料/` 已被 `.gitignore` 忽略 ——
更新框架（`git pull`）永远不会覆盖你的学习记录。

## 常见问题

**换 AI 工具会丢记录吗？**
不会。全部数据是普通 Markdown，在 `我的学习/` 里。

**要花钱吗？**
协议本身免费。AI 工具大多有免费额度（Trae 国内版每月 500 积分）。

**要懂技术吗？**
不用。会「打开文件夹」和「打字」就够了。

**我的资料会被上传吗？**
部分工具会（Trae 索引时临时上传、CodeBuddy 过腾讯云）。
敏感资料请用支持本地模型的工具（Zed / goose + Ollama）。

**AI 判错了怎么办？**
直接说「我觉得这题你判错了，理由是…」。协议要求学生可以质疑 —— 摸底结论不认同时以学生为准。

更多问题 → [`教程/01-五分钟上手.md`](./教程/01-五分钟上手.md) 的「常见问题」
