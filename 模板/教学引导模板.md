# 教学引导模板（Teaching Guide Template）

> 复制为 `NN-<课名>/01_教学引导.md`，按 8 段骨架填。**8 段的顺序不要改**。
> 学生回答文档见 [`学生回答模板.md`](./学生回答模板.md)（镜像同题）。

---

```markdown
# <学科> | NN_教学引导

## 一、为什么要学这个？

<1–2 段。必须绑定学生自己的目标。>
❌ 不要写："这是基础，很重要。"
✅ 要写："你想做 X，而 X 里必然遇到 Y，学了这个你就能 Z。"

## 二、核心概念

<这个知识点是什么、为什么存在、怎么用。一次只讲 1–2 个概念。>
<如果概念抽象，先给一个具体例子，再抽象。>

## 三、语法 / 方法 + 示例

<最小可运行（或可操作）的示例，逐行/逐句讲清。>
<代码要能跑；动作要能跟着做；论证要完整。>

## 四、新旧对比

<和已经学过的东西对比：以前怎么做，现在怎么做，区别在哪，什么时候用哪个。>

## 五、常见陷阱

<学生最容易错的 3–4 处。每处写清：错在哪 → 为什么错 → 错了会怎样。>

## 六、和之前知识的关联

<把它挂到已学的知识网络上：它依赖谁、它是谁的延伸、和谁容易混。>

## 七、本节重点（5 条）

1. <重点 1>
2. <重点 2>
3. <重点 3>
4. <重点 4>
5. <重点 5>

> 复习时只看这 5 条。

## 八、题目（按轮次排布，一次只发一轮）

> **每轮只出 1–3 题。** 导师一次只发一轮；本轮全 ✅ 后才发下一轮。
> 不要一次把下面的题目全发出去。

### 第一轮：概念理解（1–2 题）

**问题 1**：<问"为什么"，不要问"是什么">

**问题 2**：<考边界 / 考区别 / 考适用条件>

### 第二轮：动手实操（2 题）

**问题 3**：<必须在例题基础上变化条件>

**问题 4**：<必须变化条件，不能与例题同构>

### 第三轮：综合应用（1 题）

**问题 5**：<结合本课 + 之前知识，做一个完整的小任务>
```

---

## 出题自检（发出去之前过一遍）

- [ ] **本轮只出 1–3 题吗？**（不是把整课题目一次发出去？）
- [ ] 实操题与综合题是否**变化了条件**？（换数据 / 换约束 / 加边界）
- [ ] 是否**没有**与例题同构的照抄题？
- [ ] 是否有题需要**未学的知识**？（有 → 删掉或补前置）
- [ ] 是否有纯记忆题（"请复述第 3 节"）？（有 → 改成"为什么"）
- [ ] 每题是否**有明确对错**？（无标准答案的题不要出）
- [ ] 一课总题量是否在 5 题左右？（超过就砍）
- [ ] 是否用**学生的语言**写的？

## 配套阅读（必须带）

发课时一并给出，格式见 [`课程路线模板.md`](./课程路线模板.md) 末节。
**精确到篇目 + 章节 + 必读/选读 + 什么时候读**，不要只丢整篇链接。
