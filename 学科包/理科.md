# 学科包 · 理科（Science & Math）
> English version: [`理科.en.md`](./理科.en.md)

> 适用：数学、物理、化学、生物、统计、工程基础课。

---

## 1. 三维定义

| 维度 | 名称 | 判什么 | 典型 ✅ 的样子 |
|---|---|---|---|
| ① | **概念理解** | 是否理解定义、条件、适用边界 | 知道「导数 = 变化率」且知道在不可导点它不存在 |
| ② | **推导与计算** | 步骤是否成立、结果是否正确、单位是否对 | 从条件推到结论每一步都有依据，代入数值算对，单位一致 |
| ③ | **推导规范** | 符号、书写、量纲、逻辑链**结构上**正确 | 符号前后一致、等号方向对、不跳步、单位标注、条件写明 |

### 1.1 边界案例：这个错进哪一维？（只列有争议的）

通用裁决原则见 `协议/00_导师协议.md` 第 3 节（**说错了→①；想错了→②；写错了→③**）。
理科里的高频边界（本学科**最容易**出分歧）：

| 情形 | 判定 | 为什么 |
|---|---|---|
| **分类讨论遗漏**（绝对值 / 二次方程根 / 分段函数只写了一种） | **② ❌** | 推理不完备 → 「想」的问题。⚠️ 本包旧版曾把它列在 ③，**已纠正** |
| **结论对但跳步严重** | **③ ⚠️** | 推理成立，只是过程没写全。见下方「跳步判据」 |
| **符号前后不一致**（前文 `v` 后文 `u` 指同一量） | **③ ⚠️** | 形式问题，推理本身对 |
| **单位漏写** | **③ ⚠️** | 形式缺失；**若因此无法验证结果 → 升为 ③ ❌** |
| **量纲/单位算错**（`m/s + m`、厘米与米混算） | **③ ❌** | 结构性错误 —— 结果**必然**错 |
| **矢量方向漏写 / 写错** | **③ ⚠️**；影响结论正负号时 **② ❌** | 漏写符号是形式问题；若因此得错方向的结果，就是逻辑错 |
| **用了公式但没写适用条件** | **③ ⚠️**；条件不成立还硬用则 **① ❌** | 漏写条件是形式问题；**用错条件**是理解错（概念错） |
| **把「必要」当「充分」**（逆命题不成立却当成立） | **② ❌** | 推理链错 |
| **计算失误但方法对**（3×7 写成 20，后续按 21 继续） | **不扣维度**（记备注） | 是手滑不是不会。见下方「计算失误 vs 不懂」 |
| **纯数学题上的「单位」判据** | **标 `— 不适用`** | 数学题没有物理量纲；本包授权在这里不适用 |

### 1.2 「跳步」的判定阈值（这个学科最常吵的地方）

`③` 只判「**该写的步骤有没有写**」。判据是**这四类步骤必须出现**，缺任一 → **③ ⚠️**：

| 必须出现的步骤 | 例（解一道力学题） |
|---|---|
| **① 依据**（用了哪个定律/公式，写明） | 「由牛顿第二定律得……」 |
| **② 建模式**（把条件代进去的原始方程，不是跳到最后一步） | `F − f = ma` |
| **③ 中间量**（关键中间结果，至少一个有物理意义的） | 先求出 `a`，再求 `v` |
| **④ 结论 + 条件/单位** | 结果带单位；分类讨论的情形要列全 |

- **缺 1 项** → **③ ⚠️**（可代改补上）
- **缺 2 项以上，或跳过了「② 建模式」** → **③ ❌**（等于没有可检验的推导过程）
- **代回验证不是学生的答题义务**（工具性检查由导师提醒即可，不进维度）

> **一句话**：**「中间过程能不能被别人照着复现？」** 能 → 不扣；不能 → ③ ⚠️。

### 1.3 「计算失误」与「不懂」怎么区分

本包旧版只说「要区分」，这里给**可操作动作**：

| 动作 | 说明 |
|---|---|
| **问一句「这一步你是怎么想的？」** | 答得出思路（只是算错）→ **计算失误，不扣维度**，只记备注；答不出或思路本身错 → 进 **②/①** |
| **看错误分布** | 同类错误**只出现一次** → 多半是手滑；**同一处反复错** → 是理解问题 |
| **看是否可自纠** | 提示「这一步再看一眼」后自己能改 → 手滑；改完还是错 → 理解问题 |

**处置**：
- **计算失误** → 不做维度扣分，但在 `01_学生回答.md` 备注「本次 1 处计算手滑（N×N）」，并在 📊 备注记入**习惯观察**（连续 3 次同类手滑 → 进 ⏳ 待办做专项提醒）。
- **不懂** → 按正常未掌握闭环处理（Socratic → 复评）。

> **② 与 ③ 的区分**：② 判「**结论对不对**」，③ 判「**写出来的过程规不规范**」。
> 结果对了但跳步严重、符号混乱 → ② ✅ / ③ ⚠️。这是本学科最常见的评分分歧点，**必须分开标注**。

## 2. 维度 ③ 的判据

### ❌ 结构性错误（必须扣分）

> ⚠️ **归属按 §1.1 修正**：下面每项标了它**真正属于哪一维**。
> 旧版把它们一律归在「③ 结构性错误」下，是归属错位（见
> [`../docs/simulations/00-优化汇总.md`](../docs/simulations/00-优化汇总.md) 的 C1 与理科 A8）。

| 错误 | 真实维度 | 说明 |
|---|---|---|
| **量纲/单位算错**（`m/s + m`、厘米与米混算） | **③ 规范** ❌ | 结果必然错，确属结构性错误 |
| **单位漏写（导致无法验证）** | **③ 规范** ❌ | 这里「无法验证」是关键；只漏写但不影响验证 → ⚠️ |
| **符号前后不一致**（前文 `v` 后文 `u` 指同一量） | **③ 规范** ⚠️ | 形式问题，推理本身对 |
| **条件缺失**（用公式但没写适用条件） | **③ 规范** ⚠️ | 漏写条件是形式问题；**用错条件**则是 **① 概念** ❌ |
| **逻辑跳跃过大**（A 直接跳到 C，中间 B 未说明） | **③ 规范** ⚠️ | 用 §1.2 的「跳步判据」；跳过「建模式」→ ❌ |
| **等号滥用**（待求量与已知量用等号相连） | **③ 规范** ⚠️ | 书写规范问题 |
| **分类讨论不全**（该分情况时只写一种） | **② 逻辑** ❌ | 推理不完备，**不是**形式问题（旧版归错） |
| **近似不当**（小量近似用在不满足条件处） | **② 逻辑** ❌ | 推理链不成立（旧版归错） |
| **把「必要」当「充分」** | **② 逻辑** ❌ | 推理错 |
| **计算失误** | **不扣维度** | 见 §1.3 —— 先问「这一步怎么想的」再定 |

### ⚠️ 可豁免（不扣分）

- 数字笔误但过程正确（如 3×7 写成 20，后文按 21 继续）
- 单位写全称 / 简写不一致（`米` 与 `m`）
- 图形手绘不规范（草图、箭头歪）
- 有效数字位数偏好
- 使用不同但等价的符号约定（如 `ln` 与 `log` 在各自约定下）

> **关键**：手写 Markdown 的数学符号常出错（`^` 漏写、下标写成 `_` 等）→ 只要能看懂意图，不算错。

## 3. 高频问题清单

1. 背公式不理解适用条件
2. 跳步（自己懂就以为别人懂，考试会被扣分）
3. 符号混乱（同一个字母代表两个量）
4. 单位不统一（厘米和米混算）
5. 分类讨论遗漏（绝对值、二次方程根、分段函数）
6. 边界条件忽略（分母为 0、根号内为负）
7. 把「必要」当「充分」（逆命题不成立）
8. 计算失误（不是不懂，是算错——要区分开）
9. 结论不写单位 / 不写方向（矢量）
10. 检查习惯缺失（代回原式验证）

## 4. 出题形态

| 轮次 | 题型 | 要点 |
|---|---|---|
| 第一轮 | **概念题**（1–2 题） | 「X 的适用条件是什么？举一个不适用的情况」——考边界 |
| 第二轮 | **计算题**（2 题） | 必须**换数据、加边界**，不能与例题同构 |
| 第三轮 | **综合题**（1 题） | 需要两步以上、用上本课 + 之前知识 |

> **每轮只发 1–3 题，本轮全 ✅ 才发下一轮**（见 `协议/00_导师协议.md` 第 2 节）。

### 本学科的题型成本：**中～重**

按 `协议/00_导师协议.md` 第 2 节的「题型成本折算」：

| 题型 | 成本 | 一轮题量 |
|---|---|---|
| 概念题（适用条件 / 边界） | 轻 | 可到 3 题 |
| 单步计算 / 单位换算 | 轻～中 | 2–3 题 |
| **多步推导**（含分类讨论） | **重** | **1–2 题** |
| **综合题**（两步以上 + 分类讨论 + 代回验证） | **重** | **1 题** |

> **为什么**：理科一题常含「列式 → 推导 → 分类讨论 → 代回验证」四步，
> 写出来就是十几行公式。
> 8 学科仿真实测（[`../docs/simulations/07-理科-数学微积分.md`](../docs/simulations/07-理科-数学微积分.md)、
> [`08-理科-物理.md`](../docs/simulations/08-理科-物理.md)）：
> 一轮两题推导会让导师回复失控，且学生看不到重点。
>
> **允许**：「一轮 = 1 道完整推导题」完全合规。
> **提示**：物理的多步题还含画受力图，成本再高一些，倾向取 1 题。

**好的理科题特征**：
- 有唯一正确答案（或有限个）
- 藏一个边界/陷阱（分母为 0、退化情形）
- 不需要未学工具就能解
- 能检验「是否理解」而非「是否记住」

**禁止**：
- ❌ 出纯记忆题（「写出 XX 公式」）
- ❌ 出需要超纲工具的题
- ❌ 出计算量巨大但思维简单的题（那是体力活）

## 5. 验证方式

1. **代回验证**：把答案代回原式，成立吗？
2. **量纲检查**：结果的单位对不对？
3. **极限检验**：把某量取到 0 或无穷，结果合理吗？
4. **换条件**：把条件改一点，答案怎么变？为什么？
5. **讲原理**：为什么这一步可以这样变形？

> 「算出答案」可能是蒙的；**「能解释每一步为什么成立」才算掌握**。

### 费曼法在理科里怎么用

| 值得费曼的知识点 | 不值得 |
|---|---|
| 定理的**适用条件与直觉**：为什么导数能描述变化率 | 公式本身（背了就行） |
| 物理图像：为什么会有惯性、为什么熵增 | 具体积分技巧 |
| 为什么这个公式长这样（而非别的样子） | 单位换算 |
| 两个概念的本质区别（如「质量」vs「重量」） | 某个常数等于几 |

**理科费曼题的特别约束**：

- ❌ 不许写公式（「用话说，不许写数学符号」）—— 写公式等于跳过了理解
- ✅ **必须给物理/几何直觉**：「为什么速度的导数是加速度？用话说。」
- ✅ 好问法：「用**完全不懂数学的人**能听懂的话，解释什么叫『极限』。」

**典型问法**：

```
不许写公式、不许用这些词：<导数>、<极限>、<微分>

用生活里的例子解释：为什么「变化的速度」这个概念是有意义的？
（提示：想想汽车仪表盘上的速度表 —— 它显示的是什么？）
```

## 6. 不发配套阅读清单

**不要**给学生开「必读：某教材 第 3 章 §3.2」这类清单 —— 理由见 `协议/00_导师协议.md` 第 8 节：
AI 凭记忆报出的书名与章节号无法核实，且学生多半没有那本教材。

**教学内容全部写进当课的教学文档**，由导师自己讲清楚（含例题与推导）。

**如果学生自己放了资料**（`资料/` 里有教材、讲义、真题）→ 那就**直接按资料里的实际内容教**，
并注明「出自 `<文件名>` 的 `<具体章/节/题号>`」（这是真实可核对的引用，不是凭记忆）。
