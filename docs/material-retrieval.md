# 资料检索：先定位，再完整读取

这是现有「不凭记忆教学」纪律的操作指南。读取学生资料前先读 `资料/索引.md`；没有就按 `资料/README.md` 的格式新建，登记真实文件、版本与可读性。学生没有资料时，可使用已经读取并能核实的一手来源；无法取得原文时说明缺口。

## 不把整本书塞进上下文

先看索引和目录，选与当前课有关的小节；搜索标题，找不到再搜正文。搜索结果只是定位线索，教学前必须完整读对应小节，包括前提、例外、备注和必要的相邻定义。没搜到不等于资料没有：检查同义词、目录与可读性后再报告范围内未找到。

能直接读文件就用现有读文件工具或 `rg`。需要重复核对时，可选用只读工具（Node 18+，无第三方依赖）：

```bash
node tools/materials.mjs list --root .
node tools/materials.mjs list --root . --file "教材.md"
node tools/materials.mjs search --root . --query "循环"
node tools/materials.mjs read --root . --file "教材.md" --section 12
```

`--file` 相对于 `资料/`；`--section` 是目录或搜索输出的标题起始行号。读取会保留子标题，直到下一个同级或更高级标题。重复标题靠起始行区分；代码围栏里的标题不算目录。没有标题的文本省略 `--section` 读完整文件。工具支持常见 ATX/setext Markdown 标题；复杂排版要人工核对边界。

工具输出文件名、SHA-256、行号与完整原文。可给 `read` 加 `--sha256`（使用上次输出的完整指纹），来源已变则报错，重新定位后才能沿用引用。指纹仅证明读的是哪一版本，不证明内容正确。

只处理 UTF-8 `.md` / `.txt`。PDF、图片及其他格式在清单里标为本工具不能读取，先用实际可用的工具提取并核对；不能提取则停下说明需要什么。原始文件不修改，提取文本另存并在索引里标明原文件及页码对应关系。

## 把来源放在本课文档里

在 `01_教学引导.md` 的知识点附近记录已核对的依据，不新增一份学习状态：

| 知识点 | 依据 | 定位 | 核验与限制 |
|---|---|---|---|
| 循环的退出条件 | `教材.md`，学生提供版本 | 第 2 节；L12–L28；文件 SHA-256 | 已读取；仅支持本节给出的条件 |

学生看到的引用仍写「出自 `教材.md` 第 2 节」，可补行号。官方网页记录标题、URL、版本/核验日期与实际读过的小节；不要编章节、页码、数字或 DOI。区分原文结论与导师的推导；原文有争议或不确定性时一并说明。来源版本和依据是否可靠，与学生的三维掌握评估分别记录，不能相互代替。

这不会恢复课外必读书单，也不改变每轮 1–3 题、费曼题例外或整课通过才推进的规则。
