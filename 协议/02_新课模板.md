# 02_新课模板（Lesson Template）

> 用途：每次发布新课，照本文件产出两个文件：`01_教学引导.md`（导师写）+ `01_学生回答.md`（镜像同题，学生作答 + 最终复评）。
> 英文版：[`02_新课模板.en.md`](./02_新课模板.en.md)

---

## 1. 两个文件的关系（唯一真相原则）

```
学科/<学科>/NN-<课名>/
├── 01_教学引导.md     ← 导师写：讲解 + 例题 + 题目（三轮）
└── 01_学生回答.md     ← 学生写：镜像同题 + 空答案位 + 末尾两个占位区
```

- **回答文档 = 唯一学习证据**。是否掌握，以回答文档的「最终复评结果」为准。
- **不生成 HTML 副本**。需要交互练习时再按需生成，且生成物不算真相（Markdown 才是）。
- 回答文档末尾固定两个占位 H2：`## 最终复评结果`、`## 正确答案与解析` —— 评估完成后由导师填写。

---

## 2. 教学引导文档骨架（8 段，顺序固定）

```markdown
# <学科> | NN_教学引导

## 一、为什么要学这个？
<1–2 段，必须绑定学生的目标。不许写"这是基础很重要"这种空话。>

## 二、核心概念
<这个知识点是什么、为什么、怎么用。一次只讲 1–2 个概念。>

## 三、语法 / 方法 + 示例
<最小可运行（或可操作）的示例，逐行/逐句讲清。>

## 四、新旧对比
<和已经学过的东西对比：以前怎么做，现在怎么做，区别在哪。>

## 五、常见陷阱
<学生最容易错的 3–4 处，写清"为什么错"和"错了会怎样"。>

## 六、和之前知识的关联
<把它挂到已学的知识网络上。>

## 七、本节重点（5 条）
<5 条，学生复习时只看这里。>

## 八、问题（三轮）
> 可以一次全部作答；导师评估时会完整检查全部答案，一次性列出所有问题。

### 第一轮：概念理解（问题 1–2）
### 第二轮：动手实操（问题 3–4）
### 第三轮：综合应用（问题 5）
```

---

## 3. 出题纪律

| 项 | 规则 |
|---|---|
| **题量** | 默认 5 题（1–2 概念 / 3–4 实操 / 5 综合）；可按学生目标调整，不固定 |
| **变式** | 问题 3–5 必须在例题基础上**变化条件**（换数据、换约束、加边界），**不能与例题同构照抄** |
| **语言** | 用学生的语言出题 |
| **禁止** | 不许出「请复述第 3 节内容」这种考记忆的题；不许一次出超过 6 题 |

## 5. 发布新课时对学生的输出模板

```markdown
# #NN <上一课名> 已闭环 ✅            ← 若上一课刚通过
**复评结果**：概念、逻辑、规范全部通过。
首次评估发现 N 处问题，已按你的要求直接代改：1)… 2)… 3)…
学习档案也已同步更新。
---
**下一步：#NN <新课名>**（<一句为什么值得学，绑定你的目标>）
### 📁 文档位置
- 教学引导：<路径>
- 回答文档：<路径>
### 📖 本课重点（5 条）
### 📚 配套阅读
- 必读：<篇目> §<章节号> <章节名>（课前读 / 课后对照 / 自测来源）
- 选读：<篇目> §<章节号> <章节名>（什么时候再回来看）
- 本课自测来源：<篇目> §<自测题章节>
### ✅ 你的任务
阅读完教学引导后，在回答文档里完成**本次全部题目**，然后告诉我"完成了"即可。
> 复习触发提醒（不阻塞）
```
