# 02_Lesson Template

> Purpose: every time you publish a new lesson, produce two files per this document: `01_教学引导.md` (written by the tutor) + `01_学生回答.md` (mirrors the same questions; the student answers, then the final re-assessment).
> Chinese version: [`02_新课模板.md`](./02_新课模板.md)

---

## 1. How the two files relate (single source of truth)

```
学科/<学科>/NN-<课名>/
├── 01_教学引导.md     ← tutor writes: explanation + worked examples + questions (three rounds)
└── 01_学生回答.md     ← student writes: mirrored questions + blank answer slots + two placeholder sections at the end
```

- **The answer document = the only learning evidence.** Mastery is judged by its "Final Re-assessment".
- **No HTML copy is generated.** Generate one on demand only when interactive practice is needed, and the generated artifact is not truth (Markdown is).
- The answer document always ends with two placeholder H2s: `## Final Re-assessment`, `## Correct Answers & Analysis` — filled in by the tutor after assessment.

---

## 2. Teaching guide skeleton (8 sections, fixed order)

```markdown
# <subject> | NN_Teaching Guide

## 1. Why learn this?
<1–2 paragraphs, must be tied to the student's goal. Empty talk like "this is fundamental and important" is forbidden.>

## 2. Core concepts
<What this topic is, why, and how to use it. Only 1–2 concepts at a time.>

## 3. Syntax / method + examples
<A minimal runnable (or actionable) example, explained line by line / sentence by sentence.>

## 4. Old vs new
<Compare with what's already learned: how it was done before, how it's done now, where the difference lies.>

## 5. Common traps
<The 3–4 places students get wrong most, spelling out "why it's wrong" and "what happens when it's wrong".>

## 6. Links to prior knowledge
<Hook it onto the knowledge network already built.>

## 7. Key points of this lesson (5)
<5 items; when reviewing, the student only reads here.>

## 8. Questions (three rounds)
> You may answer all of them at once; the tutor checks every answer and lists all problems in one pass.

### Round 1: conceptual understanding (questions 1–2)
### Round 2: hands-on practice (questions 3–4)
### Round 3: synthesis (question 5)
```

---

## 3. Question-writing discipline

| Item | Rule |
|---|---|
| **Count** | Defaults to 5 (1–2 concept / 3–4 hands-on / 5 synthesis); adjustable to the student's goal, not fixed |
| **Variation** | Questions 3–5 must **change the conditions** of the worked examples (new data, new constraint, new edge case) and **must not be same-shape copies** |
| **Language** | Write questions in the student's language |
| **Forbidden** | No memory-recall questions like "recite the content of section 3"; never more than 6 questions at once |
