# 0008 · 费曼法作为自适应诊断工具

- **状态**：已接受
- **日期**：2026-09-21
- **决策者**：项目发起人

---

## 背景

项目原有「费曼讲解」机制，但只有一行：

> | 🗣️ **费曼讲解** | 每完成一个大模块 | 学生用通俗语言向完全不懂的人解释核心概念 | 讲不清 = 没真懂 |

三个问题：

| 问题 | 后果 |
|---|---|
| **没说怎么问** | 导师可能问「请解释一下 X」—— 学生直接背定义，测不出理解 |
| **没说怎么评** | 硬套三维标准会误判（学生用口语讲概念，本来就不该要求形式规范） |
| **触发条件太粗** | 「每完成一个大模块」既不适用于纯操作型内容，也没考虑学生程度差异 |

而费曼法恰恰是本项目最有价值的诊断工具 —— 因为**它测的是「你以为你会，其实你不会」**。

---

## 决策

**把费曼法升级为贯穿全流程的自适应诊断工具，写入 `协议/00_导师协议.md` 第 6.1 节专节。**

### 1. 定位：诊断工具，不是练习题

| 普通题 | 费曼题 |
|---|---|
| 可以套公式、背模板、靠熟悉度蒙对 | 必须自己组织语言，套不了 |
| 答对 ≠ 真懂（可能是模式匹配） | **讲不清 = 一定没懂**（几乎不会误判） |
| 测「能不能做」 | 测「是不是真理解」 |

### 2. 频率自适应（用户明确要求「不用非常频繁」）

按五个因素动态判断：**知识点性质 / 学生学习程度 / 此前信号 / 课程阶段 / 学科特点**。

**硬性下限与上限**（防止滥用与遗漏）：

- ✅ 大模块收尾**必做 1 次**（不可省）
- ✅ 一个知识点**最多问 2 次**（首次诊断 + 后续确认）
- ❌ 不许每课都问；不许连续两轮都出费曼题
- ❌ 学生说「我不想讲，直接考我」→ **尊重他**，改用普通题

> **判断口诀**：**「这个知识点，背下来能不能过？」** 能过 → 不必费曼；不能过 → 值得费曼。

### 3. 怎么问：三种问法 + 三条纪律

| 问法 | 适用 |
|---|---|
| ① 讲给外行 | 通用，最经典 |
| ② 讲给小孩 | 概念特别抽象时 |
| ③ 类比 + 反例 | 学生程度较高时 |

**纪律**：必须明确指定听众｜必须禁止术语｜一次只问 1 题。

### 4. 怎么评：不按普通三维

**费曼题只评维度 ① 概念理解**，另两项标 `— 不适用`。判据是**听众能不能听懂**，不是「说得对不对」。

三级判据：✅ 讲清了 / ⚠️ 半懂 / ❌ 没懂，附**五个「讲不清」的典型征兆**（一开口就是术语、背教材原句、举不出例子…）。

### 5. 评完怎么反馈

- ✅ 讲清 → 明确肯定 + **指出讲得好的那一句**（不是敷衍的「讲得不错」）
- ⚠️ 半懂 → 指出卡住的术语，**只重讲那一段**，不要全篇重来
- ❌ 没懂 → **不批评**（这恰恰是价值：暴露了漏洞）→ 重讲 → 再讲一次

**归因纪律**：讲不清时**归因到知识本身**，不要归因到学生能力。

## 学科差异化（用户明确要求「根据学习内容而定」）

| 学科 | 值得费曼 | 特别约束 |
|---|---|---|
| 编程 | 闭包、引用传递、多态、递归 | **禁止写代码**（否则直接贴代码，测不出理解） |
| 语言 | 语法背后的逻辑、中英思维差异 | **用母语讲**（更能暴露理解）；不许背语法书 |
| 文科 | 抽象概念、因果解释 | **必须举具体例子**；不许复述教材定义 |
| 理科 | 定理的适用条件与直觉 | **禁止写公式**；必须给物理/几何直觉 |
| 应试 | 反复错的同源概念（少数） | **要克制** —— 备考时间紧，大模块收尾做 1 次即可 |

---

## 理由

| 理由 | 说明 |
|---|---|
| **测出最危险的「不会」** | 套公式能答对的题，费曼题会露馅 |
| **几乎不会误判** | 讲不清 → 一定没懂；这是最强的反向证据 |
| **自适应，不折磨学生** | 用户明确要求「不用非常频繁」，硬性上限防滥用 |
| **学科可适配** | 每个学科包给出该学科的问法与禁忌 |
| **可落档** | 费曼结果写进掌握表备注，成为**比做对题更强的掌握证据** |

---

## 备选方案与为何否决

| 方案 | 否决理由 |
|---|---|
| 保持原样（一行表格） | 没说怎么问、怎么评，导师执行会走样 |
| 每课都问费曼 | 用户明确要求「不用非常频繁」；且纯操作型内容问了没意义 |
| 费曼题也按三维评 | 用口语讲概念本来就不该要求形式规范，会误判 |
| 固定「每 N 课问一次」 | 不区分知识点性质与学生程度，机械 |
| 不提供学科差异 | 编程不禁止写代码、理科不禁止写公式 → 学生直接贴答案，测不出理解 |

## 代价（明确接受）

| 代价 | 缓解 |
|---|---|
| 费曼题耗时远高于普通题 | 该轮**只出 1 题**；频率自适应 |
| 判据主观（「听众能不能听懂」） | 提供三级判据 + 五个典型征兆，降低主观性 |
| 学生可能抵触「讲一遍」 | 允许拒绝（尊重偏好）；题面明确写「讲不清很正常」 |
| 多一层判断负担（该不该问） | 给出五因素表 + 判断口诀 |
