# My Rules (我的规则)

> **This is your rules file, and it has the highest priority.**
> Every time the tutor takes over, it reads this **first**, then the framework defaults (`协议/00_导师协议.md`).
> **Anything written here overrides the framework defaults.**
>
> You can: change any entry, delete what you don't want, add your own, write your own teaching preferences.
> Not sure how? Just tell the tutor "I want to change X to Y" — it will write it into this file.

> Chinese version: [`我的规则.md`](./我的规则.md)

## How to use it

**This file starts empty (everything is commented out) — empty means "use all framework defaults", and that's perfectly fine.**

To change something, **remove the `<!--` and `-->` around that line** (uncomment it) and set your value.

Three ways, pick any:

| Way | What to do |
|---|---|
| **Edit directly** | Edit this file: uncomment and change |
| **Just say it** | Tell the tutor "only 1 question per round from now on" → it writes it in for you |
| **Change nothing** | Keep everything commented = use all framework defaults |

**Example of uncommenting**:

```markdown
<!-- Before: this line is a comment, it has no effect -->
<!-- - Questions per round: 2 -->

<!-- After: it takes effect and overrides the framework default -->
- Questions per round: 1
```

## Rule priority (for the tutor)

**Priority, highest to lowest**:

```
1. This file (我的规则.md)          ← highest, overrides everything below
2. What the student says in the moment  ← overrides 3 and below
3. 我的学习/00-学习档案.md 🚦       ← current progress (state, not a rule)
4. 协议/00_导师协议.md              ← framework defaults
5. 学科包/<subject>.md              ← that subject's assessment criteria
6. The rest of AGENTS.md            ← framework entry
```

**On conflict**: the higher entry wins.
**Not written here**: use the framework default.
**Written here**: this file wins, even if it contradicts the framework default.

> **One exception**: if this file contains two **contradictory** rules, the tutor must **ask you** which one you want — never guess.

## Operating instructions for the tutor

| Situation | What to do |
|---|---|
| Student says "change it to X from now on" | Write X into this file (**do not edit `协议/`** — that is read-only framework) |
| Student says "I don't like Y" | Same: turn it into an explicit rule here |
| This file is empty | Use all framework defaults; **do not write anything into it unprompted** |
| Two rules contradict each other | **Ask the student** which one they want; don't pick for them |
| You want to suggest a rule | You may propose it, but only write it in **with the student's agreement** |
