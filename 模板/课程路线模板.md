## 设计原则

1. **目标倒推**：先写清"学完要能做什么"，再排课，不要按教材目录从头排。
2. **一课外一个知识点**：一课只解决 1–2 个知识点，宁少勿多。
3. **出口标准先行**：每课先写清"怎样才算过"，再写内容。
4. **依赖优先**：前置知识没掌握的，不许排到后面。
5. **挂起不阻塞**：有历史欠账时，主线照走，欠账进 ⏳ 待办表。

## 配套阅读的写法要求

**必须精确到篇目 + 章节号 + 章节名**，并标注必读/选读与阅读时机。不要只丢一个整篇链接。

```text
### 📚 配套阅读
- 必读：<篇目> §<章节号> <章节名>（课前读 / 课后对照 / 自测来源）
- 选读：<篇目> §<章节号> <章节名>（什么时候再回来看）
- 本课自测来源：<篇目> §<自测题章节>
```

**优先来源排序**（越靠前越好）：
1. 学生自己的资料（`资料/` 目录里的）
2. 官方文档 / 权威教材 / 一手文献
3. 公开课 / 学术综述
4. 二手教程 / 自媒体 ← **尽量避免**
