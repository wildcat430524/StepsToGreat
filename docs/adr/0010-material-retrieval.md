# 0010 · 用完整小节与版本指纹支撑资料引用

- **状态**：已接受
- **日期**：2026-09-30
- **依据**：用户授权参考 HowToLiveBetter 升级项目与 skill

## 问题与决策

现有协议要求可核实引用，但没有提供可重复的「搜索后完整读取小节」工具。Steps2Great-skill 入口重复协议细节，还遗漏了多学科切换的入口约束。

借鉴 [HowToLiveBetter 的 skill](https://github.com/eternity4719/HowToLiveBetter/blob/main/skills/life-decision-guide/SKILL.md) 的先定位、完整读取条目（含例外）、标明出处做法：增加可选只读检索工具和操作指南；给引用附来源行号与文件指纹；skill 入口缩短为关键约束与按需路由，具体评估仍读原协议。

不直接迁入人生建议、性价比排序或 A/B/C 分级。教学依据的可靠性与学生是否掌握是不同问题；来源多不等于学会。

## 边界与验收

不修改 `AGENTS.md`、`协议/`、`模板/`、`学科包/`、`_tools/` 或学生规则、进度。新增工具不是开课依赖：无 Node 时照常使用文件读取工具。支持 UTF-8 Markdown/text，其余格式明确报告本工具不能读。

检索工具验收覆盖子节及例外完整性、重复标题、围栏、文件版本变化、未命中、路径越界和不可读格式。工具与指南通过映射同步到 skill，连续同步应保持一致。现有状态回归验证掌握闸门仍然有效。

## 同步时发现的缺口与补齐

独立只读审查发现 skill 的 `sync --dry` 只输出计划，原自检没有比较镜像文件内容。新增 `--check` 逐文件比对，内容过期或缺失均非零退出；自检使用该模式，并正确传入指定上游目录。同步现有协议版本与多学科落档文档，保留 skill 独占的校验器修复，再补 I12 协议版本握手、资料索引指导与规则变更记录。
