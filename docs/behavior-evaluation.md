# 导师行为评测

本项目现在分别检查静态内容、学习档案自洽性，以及运行中实际发生的工具调用。行为评测覆盖 12 个合成场景：重新读取当前答案、完整评估多题、计算与概念错误、历史追加、先读后写、轮次题量、自定义题量、费曼独占与评估例外、原文引用、不可读资料。

## 先运行框架自测

需要 Node 18+，不需要额外依赖或模型密钥：

```bash
npm run test:behavior
node tools/behavior-eval.mjs --list
node tools/behavior-eval.mjs --adapter evals/behavior/fixture-adapter.mjs --model fixture-only --out reports/behavior-self-test
```

第三条命令运行预先编写的正向对照脚本。报告明确标为 `fixture-self-test`；它的通过率只说明评测框架能接受这些正确操作，不能当作 AI 模型通过率。回归测试另外注入错误：漏读、重复评估、覆盖历史、超量出题、错误标签、伪造引用、超时和进程崩溃等，确认评测器会拒绝。

## 接入真实 Agent

创建一个可信的本地 ES module，导出 `async run({ input, protocol, tools })`。每次调用代表一个独立场景；将 `protocol` 和 `input.message` 交给被测 Agent，将下面六个方法映射成其真实工具。只有模型请求了对应操作，适配器才应调用该方法；不要替模型补读文件、补评估或补引用，否则测到的是适配器补救后的行为。

| 工具 | 参数与返回 | 记录或检查 |
|---|---|---|
| `readFile` | 相对路径 → 文本；不可读时抛错 | 文件版本与调用顺序 |
| `writeFile` | 路径、完整新文本 | 修改前已读；回答历史保持前缀 |
| `assess` | 一次提交本轮所有题目的数组 | 完整性、独立维度、参考标签、当前答案已读 |
| `publishRound` | `{kind, prompt}` 数组 | 当前轮已通过、题量、一轮费曼独占 |
| `cite` | `{path, quote, sha256}` | 指定来源已读、版本匹配、原文确有此句 |
| `reportGap` | 路径、缺口原因 | 实际读失败后说明缺口 |

评估数组每项为 `{id, concept, logic, expression}`，每个维度取 `PASS`、`WARN`、`FAIL`、`NA`。题目 `kind` 取 `normal` 或 `feynman`。来源版本使用实际读到文本的 SHA-256。适配器可返回 `{usage: {inputTokens, outputTokens, costUSD}}`；没有取得真实用量时省略，不能填估计值冒充记录。

`input` 包含任务、文件路径和虚拟工作区内容；隐藏的 `expected` 参考标签与判定策略不传给适配器。模型实际读取仍应经 `readFile` 执行并记录，不能把全部 `input.files` 直接当作模型已读的证据。

```bash
node tools/behavior-eval.mjs --adapter adapters/my-agent.mjs --model my-model-version --out reports/my-model
```

适配器文件由接入者提供；仓库没有内置真实模型连接，也不会自行调用付费 API。`--protocol` 可以指定实际使用的协议入口，skill 版应使用 `SKILL.md`。真实客户端可能自动读取更多规则，适配器应传入或记录相同环境，比较报告时核对协议范围。

每个场景在独立子进程里执行，默认超时 30 秒；`--timeout-ms` 可设为 1–300000 毫秒。适配器模块是可信可执行代码，虚拟文件工具和子进程隔离不构成操作系统安全沙箱。超时或崩溃计为失败，继续执行剩余场景。退出码：0 全部通过；1 行为失败；2 配置或输入错误。

输出 `.json` 和 `.md` 两份报告：包含每个场景的结果、违规规则、工具事件、耗时，以及场景集、协议入口和适配器的 SHA-256。模型名由运行者填写，用于追踪，框架无法核验服务商或模型身份。token 与费用只在适配器提供时记录。上传报告前应检查日志中是否包含私人资料。

## 指标的边界

- 工具轨迹证明调用发生及顺序，不能证明模型理解了文件，或自然语言回复与结构化工具输出一致。
- 引用检查证明版本与摘录存在，不能证明摘录支持结论，也不能保证全部前提与例外都被理解。
- 本场景集参考标签由维护者编写，尚未经过独立教师标注；题量与覆盖范围适合回归，不代表跨学科批改准确率。
- 正向脚本和故意错误测试是评测器自测；真实模型成绩必须来自对应适配器运行，不能把这两类数字混用。
- 学生学习效果仍需真实用户前测、后测与延迟变式测试。本次没有产生这类证据。

扩展场景时修改 `evals/behavior/scenarios.json`，同时增加能通过的控制轨迹和能被拒绝的错误轨迹。不同场景版本、不同完整协议或不同参考标签的报告应分别呈现，不直接合并成一个排行榜。
