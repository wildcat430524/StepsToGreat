# 01 · 五分钟上手

> 目标：**5 分钟**从「下载这个文件夹」到「和 AI 导师说上话」。
> 不需要懂编程，不需要 API Key（推荐的工具都是免费额度起步）。
> English version: [`01-five-minute-setup.en.md`](./01-five-minute-setup.en.md)

---

## 你要准备什么

| 项 | 要求 |
|---|---|
| 电脑 | Windows 10/11、macOS 或 Linux |
| 网络 | 能上网（AI 需要联网） |
| 一个 AI 工具 | 见下方「第 2 步」，推荐 **Trae**（免费、中文、图形界面） |
| 时间 | 5 分钟 |

**不需要**：编程基础、Git、Node.js、API Key、信用卡。

---

## 第 1 步 · 把这个文件夹放到你能找到的地方

假设你放在了：

```
E:\StepsToGreat
```

> 📌 **重要**：把它放在**你自己能记住的路径**，不要放在临时目录或下载文件夹里。
> 这个文件夹就是你的「学习档案」，里面会不断积累你的学习记录。

---

## 第 2 步 · 装一个 AI 工具

**推荐顺序**（都免费、都支持中文、都能打开文件夹）：

| 排名 | 工具 | 为什么推荐 | 免费情况 |
|---|---|---|---|
| 🥇 | **Trae** | 中文界面、图形化、无需 API Key、Windows 可用 | 国内版 ¥0，每月 500 积分 |
| 🥈 | **腾讯 CodeBuddy** | 中文、微信扫码登录 | 体验版 500 积分/月 |
| 🥉 | **阿里 Qoder** | 原生认 `AGENTS.md`，零配置 | 有免费额度 |
| 4 | **Cursor** | 生态最成熟 | Hobby 免费档 |

详细对比与逐软件安装步骤 → [`02-各工具接入指南.md`](./02-各工具接入指南.md)

**这里以 Trae 为例**（因为它是唯一「全中」的）：

1. 浏览器打开 `https://www.trae.cn`（国内版）
2. 点「下载」→ 选 Windows → 下载 `.exe`
3. 双击安装，一路「下一步」
4. 打开 Trae，用手机号或微信扫码登录（**不需要信用卡**）

---

## 第 3 步 · 打开文件夹（关键）

在 Trae 里：

```
文件 → 打开文件夹 → 选中 E:\StepsToGreat
```

打开成功后，左侧文件树应该能看到 `AGENTS.md`、`协议/`、`我的学习/`：

```
┌─────────────────────┐
│ ▾ 📁 STEPSTOGREAT   │
│   📄 AGENTS.md  ← 有它才对 │
│   📁 协议/          │
│   📁 学科包/        │
│   📁 我的学习/      │
│   📁 资料/          │
└─────────────────────┘
```

> ⚠️ **打开的是文件夹本身**，不是里面的某个 `.md` 文件。
> 这一步选错，AI 就读不到规则，后面全部无效。
> 完整界面示意（纯文本，无截图）→ [`界面示意图.md#4`](./界面示意图.md#4-打开文件夹-容易错的一步)

---

## 第 4 步 · 打开「读 AGENTS.md」开关（Trae 用户必看）

**这一步 90% 的人会漏掉。**

Trae **默认不读** `AGENTS.md`，需要手动打开：

```
设置（左下角齿轮）→ 规则 → 导入设置
→ 打开「将 AGENTS.md 包含在上下文中」
```

> ⚠️ **界面可能与你看到的不完全一样。** 上面这条是**操作路径**（以官方文档为准）；
> [`界面示意图.md`](./界面示意图.md) 里的框图只是示意，**排版/措辞可能与实际有出入**。
> 找不到时：在设置里搜 `AGENTS.md` 或 `规则`。

> 💡 本项目已经在 `.trae/rules/` 放了跳板文件（`alwaysApply: true`），
> 所以**即使你忘了开这个开关，大概率也能用**。
> 但**建议还是打开**，双保险。
> 这个开关长什么样 → [`界面示意图.md#5`](./界面示意图.md#5-打开规则开关-最关键90-的人卡在这)

**其它工具需不需要这一步？**

| 工具 | 需要手动开吗 |
|---|---|
| Cursor / Qoder / Codex / Cline / Zed | ❌ 不需要，零配置 |
| **Trae** | ✅ **需要**（见上） |
| **Claude Code** | ⚠️ 本项目已放 `CLAUDE.md` 跳板，无需操作 |
| **腾讯 CodeBuddy** | ⚠️ 本项目已放 `CODEBUDDY.md` 跳板，无需操作 |
| **Gemini CLI** | ⚠️ 本项目已放 `GEMINI.md` 跳板，无需操作 |

完整矩阵 → [`../docs/AGENT-COMPAT.md`](../docs/AGENT-COMPAT.md)

---

## 第 5 步 · 说第一句话

在 Trae 的对话框里，**原样复制这句**：

```
我是学生，请先读 AGENTS.md，然后开始。
```

**然后你会看到 AI：**

1. 读 `AGENTS.md`
2. 读 `我的学习/00-学习档案.md`（发现是空的）
3. 问你 3 个问题：**学什么 / 以前接触过吗 / 目标是什么**
4. 带你做摸底测试（5–8 题，约 10 分钟）
5. 定起点、排路线、发第一课

---

## 第 6 步 · 确认它真的读到了规则（重要）

**怎么验证？** 直接问它：

```
请复述一下 AGENTS.md 里「硬规则」那部分，有几条？
```

- ✅ **答得出**（应该回答 9 条硬规则）→ 一切正常，继续
- ❌ **答不出 / 说找不到文件** → 回到第 3、4 步检查

> 这是**唯一可靠的验证方式**。很多工具没有「查看已加载规则」的界面，
> 所以只能靠让它复述来确认。

---

## 之后你只需要说两句话

| 场景 | 你说 |
|---|---|
| 想继续学 | 「继续」或「我准备好了」 |
| 做完作业了 | 「**完成了**」 |

AI 收到「完成了」会自动：
1. **重新读**你的回答文档（不靠记忆）
2. **一次性**评估全部题目（三维：概念 / 逻辑 / 规范）
3. 有小问题 → **直接帮你改**，并讲清「你写的 → 错在哪 → 我改成什么」
4. 全过了 → 落档 + 发下一课

## 常见问题

### Q：AI 说读不到 AGENTS.md 怎么办？

按顺序检查：
1. 你打开的是**文件夹**还是单个文件？（必须是文件夹）
2. Trae 用户：第 4 步的开关开了吗？
3. 文件夹里真的有 `AGENTS.md` 吗？（在根目录，不在子目录）
4. 换一个工具试试（见 [`02-各工具接入指南.md`](./02-各工具接入指南.md)）

### Q：我的资料要放哪？

放进 `资料/` 目录（没有就自己建一个）。AI 会从那里读。

支持的格式：`.md` `.txt` `.pdf` 最稳；图片需要 AI 有视觉能力。

### Q：换工具会不会丢失学习记录？

**不会。** 你的全部记录都在 `我的学习/` 目录里，是普通 Markdown 文件。
换任何工具，只要打开同一个文件夹，就能接着学。

### Q：我能同时学好几科吗？

能。`我的学习/学科/<学科名>/` 下每科一个目录，`我的学习/00-学习档案.md` 管全局。

### Q：AI 会把我文件夹的内容传到网上吗？

**部分工具会。** 已知情况：
- Trae 官方承认索引时会**临时上传文件**做 embedding
- CodeBuddy / WorkBuddy 个人版内容会过腾讯云
- Kilo Code 的免费通道官方明示**会记录**输入输出

**如果资料敏感**：用支持本地模型的工具（Zed / goose / opencode + Ollama），或不要放敏感内容。

### Q：学完能删掉吗？

能。整个文件夹删掉即可，没有后台服务、没有注册账号、没有云端存储（除了你选的那个 AI 工具）。
