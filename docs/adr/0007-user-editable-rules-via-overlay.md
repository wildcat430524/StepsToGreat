# 0007 · 规则可自定义：覆盖层而非改源码

- **状态**：已接受
- **日期**：2026-09-21
- **决策者**：项目发起人

---

## 背景

框架自带一套默认教学规则（三维评估、代改协议、每轮 1–3 题…）。
但每个学习者的情况不同：

- 有人节奏慢，希望每轮只出 1 题
- 有人讨厌 emoji，或希望导师一律用中文
- 有人喜欢直接给答案，不想被 Socratic 绕
- 有人有特殊约束（每天只有 30 分钟、只有周末有空）

**需求**：用户应该能自定义学习规则。

**矛盾**：框架文件（`协议/` `学科包/` `模板/`）必须是**只读**的 —— 否则：

| 如果让用户直接改框架 | 后果 |
|---|---|
| 用户改了 `协议/00_导师协议.md` | 下次 `git pull` **冲突或覆盖**，用户的改动丢失 |
| 多个用户各自改同一文件 | 无法同步框架更新 |
| 规则散落在各处 | 无法判断「哪条是默认、哪条是用户改的」 |
| AI 读到被改乱的协议 | 规则漂移，行为不可预期 |

---

## 决策

**采用「覆盖层」：用户的规则单独存一份，优先级最高；框架保持只读。**

新增文件 `我的学习/我的规则.md`：

- 放在**数据目录**（`我的学习/`）里，所以 `git pull` 永不冲突
- 在 `.gitignore` 里**显式保留**（`!我的学习/我的规则.md`），用户一打开就能看到
- **优先级最高** —— 它写了的覆盖框架默认；没写的用框架默认
- 支持三种使用方式：直接编辑 / 口头让 AI 写进去 / 完全不用

### 规则优先级（写进 `AGENTS.md`）

```
1. 我的学习/我的规则.md        ← 用户自定义，最高
2. 学生当场说的话
3. 我的学习/00-学习档案.md 🚦   ← 当前进度（状态，不是规则）
4. 协议/00_导师协议.md          ← 框架默认
5. 学科包/<学科>.md
6. AGENTS.md 其余部分
```

### 配套的契约改动

| 改动 | 位置 |
|---|---|
| 接手顺序新增第 0 步：**先读 `我的规则.md`** | `AGENTS.md` §1 |
| 硬规则第 10 条：学生要改规则 → **写进 `我的规则.md`，不要改框架** | `AGENTS.md` §2 |
| 硬规则第 11 条：学生提出规则性要求时，**主动提议写进规则文件** | `AGENTS.md` §2 |
| README 新增「学习规则（可以改成你自己的）」章节 | `README.md` |

---

## 理由

| 理由 | 说明 |
|---|---|
| **用户完全自由** | 想改什么改什么，包括改掉核心机制（有代价提示，但不阻止） |
| **框架不漂移** | 框架文件保持只读，`git pull` 永远干净 |
| **可审计** | 「默认是什么」和「用户改了什么」分得清 |
| **换工具/换会话仍生效** | 规则是文件，不依赖对话记忆 |
| **零学习成本** | 不改也能用；想改时可以直接跟 AI 说，不用自己写 Markdown |

---

## 备选方案与为何否决

| 方案 | 否决理由 |
|---|---|
| 让用户直接改 `协议/` | `git pull` 冲突；且框架无法更新 |
| 用 git 分支隔离用户规则 | 非技术用户不可能理解分支 |
| 把规则放仓库外（如 `~/.steps-to-great/`） | 用户找不到；「文件夹即项目」的直觉被破坏 |
| 做一套配置 UI | 需要开发 + 维护；Markdown 文件已足够 |
| 完全不允许自定义 | 用户明确要求可改；且真实需求差异大 |
| 让用户 fork 后自己改 | 门槛太高；且拿不到上游更新 |

---

## 代价（明确接受）

| 代价 | 缓解 |
|---|---|
| 用户可能改掉核心机制（如「三维全 ✅」），导致项目退化成普通聊天助手 | 在 `我的规则.md` 与 README 里**明确写出代价**（「改了之后你就知道代价是什么」），但不阻止 —— 这是用户的选择 |
| 用户可能写出自相矛盾的两条规则 | 协议规定：**导师遇到矛盾应问用户要哪一条，不要自己猜** |
| 多一层文件，AI 要多读一个文件 | 该文件通常很短；且换来「规则不漂移」的收益 |

---

## 影响

- `AGENTS.md` 接手顺序与硬规则均已更新（第 0 步 + 第 10、11 条）
- `我的学习/我的规则.md` 为模板态：内容多为注释，取消注释即生效
- `.gitignore` 显式保留该文件
- README（中英）新增「学习规则」章节，含可改项表格与优先级说明
- `我的学习/README.md` 补充「想改教学规则？」一节
